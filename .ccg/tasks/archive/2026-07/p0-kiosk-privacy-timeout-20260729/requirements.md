# 公共终端硬性隐私超时与全路由清场

## 目标

在不取消或重启后台打印/扫描任务的前提下，为所有 Kiosk 终端路由建立统一、不可被 busy 无限抑制的公共会话安全边界；闲置或硬截止后立即遮罩、清除会员与匿名敏感状态、可靠登出并回到干净首页，浏览器后退不得恢复上一位用户数据。

## 功能归位声明

- 业务闭环：公共终端跨用户隐私清场。
- 前端：仅 `apps/kiosk` 的根路由安全布局、idle/busy hook、敏感 session 清理与浏览器回归。
- 后端：默认不涉及；只有现有 logout 契约确实无法可靠失效时才另行提案，本任务不新增 API。
- Terminal Agent：不涉及；后台打印/扫描任务必须继续。
- Admin / Partner：不涉及；不新增远程控制入口。
- 共享类型 / UI：默认不涉及。
- 文档：实施计划、正式进度和审查记录。

## 必须满足

1. 所有 Kiosk 业务路由共享同一个非视觉会话安全根；手机辅助路由明确分组，不误套 27 寸终端超时。
2. 普通 idle 可以尊重有界 busy，但必须另有不受 busy 抑制的硬性隐私截止。
3. 清场先遮罩并 fail-closed，再清会员认证、匿名 AI access token、打印/扫描/材料等敏感 session，最后 replace 到干净入口。
4. 后端 logout 尽力可靠送达；本地清场不得依赖网络成功。
5. busy 只覆盖真实在途操作，成功、失败、过期、断网或硬超时必须释放；不得以取消后台打印/扫描任务实现清场。
6. 浏览器回归覆盖会员/匿名、屏保开关、顶级面试/简历路由、收银/材料/打印/扫描状态及浏览器后退。
7. 修复过期的扫描 capabilities 测试夹具；独立 truth 套件恢复全绿。

## 明确不做

- 不新增业务入口、页面、AI 能力或后台功能。
- 不修改八大功能的产品内容、岗位/招聘会合规边界。
- 不部署、不改生产、数据库、密钥、Windows 或真机。
- 不把 Admin 远程清场作为本地安全边界替代品。
- 不顺手重构无关 Kiosk 页面。

## 预期验证

- 新增测试严格经历 RED → GREEN。
- Kiosk typecheck、lint、生产 HTTP build。
- 公共终端清场 Playwright 与独立 `test:browser:truth`。
- 既有 W2/W3/W6 聚焦回归和真实性静态门禁。
- 依赖安全、无硬编码密钥、最终双模型安全审查。
