# 首页招聘会与打印扫描专区视觉平衡优化

## 目标

- 降低“招聘会”和“打印扫描”相对其他专区过度突出的体量、色块与密度。
- 统一专区标题、入口卡片、图标、间距、禁用态和文字层级。
- 保留首页所有既有入口、文案语义、路由、禁用条件和真实功能。

## 边界

- 只允许修改首页相关组件/样式、专项 verify、浏览器用例与必要进度文档。
- 不修改任何 API、DTO、Prisma、认证、权限、支付、打印/扫描任务、岗位/招聘会合规语义。
- 不修改 `ProfilePage`、`/me/*` 或其生产文件。
- 未获得用户对可视化设计的明确批准前，不修改生产代码。

## 验收

- 1080×1920 首页两个专区与其他专区层级协调，无横向溢出、裁切、重叠或底栏遮挡。
- 390×844、390×700、430×932、760×1024 使用物理移动壳；844×390、932×430、932×800 使用稳定横屏移动壳；800×932、961×760、1024×768 与 1080×1920 保持 staged kiosk 壳。
- 横屏判定使用 `width <= 960px && width > height`，不得依赖浏览器地址栏可能改变的固定高度阈值。
- 打印扫描五卡移动端均为 80px，前四项两列、末项通栏；`prefers-reduced-motion` 下所有首页按压位移关闭。
- 所有入口路由、禁用态和首页专项门禁通过。

## 用户确认的设计方向

- 优先优化 390×844 与 390×700 手机窄屏，同时保证 1080×1920 一体机不退化。
- 采用方案 A「分区有别，节奏统一」：招聘会保留轻量列表；打印扫描在窄屏压缩为两列紧凑横向磁贴，最后一项通栏。
- 保留既有入口顺序；主能力轻量强调，禁用能力使用中性低对比状态。
