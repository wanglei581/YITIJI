# Kiosk 87 页运行时视觉缺陷审计

## 目标

- 对当前 `http://127.0.0.1:58245/` 运行实例做真实浏览器审计，不能以路由可达替代页面验收。
- 复现并定位用户反馈的点击后乱码、页面错误和排版异常。
- 将问题绑定到具体路由、点击步骤、截图、控制台证据和代码根因。
- 根因确认后按独立文件所有权分批修复，并保持真实数据、加载、空态、错误、重试、权限和原有功能语义。

## 范围与预算

- 第一阶段只读审计 87 个正式 Kiosk 路由及其现有共享壳层。
- 第二阶段只修复已复现且有根因证据的问题；每批先补静态 verify 或组件/E2E 测试取得 RED，再实现 GREEN。
- 禁止用原型假数据、演示登录或本地假状态覆盖真实业务状态。
- 不修改 API、DTO、Prisma、认证、权限、支付、打印、扫描、AI、TRTC、Terminal Agent 或招聘合规语义，除非审计证明前端修复无法成立并另行获得授权。
- 不把视觉对齐扩大为全仓重命名或 87 页无证据重写。

## 验收

- 重要问题均有当前审计轮次的浏览器截图与复现步骤。
- 所有修复通过对应 RED/GREEN 门禁、Kiosk typecheck/lint/build、新增 verify 与 `git diff --check`。
- 关键视口用真实浏览器复验；明确区分本地证明和真机/预生产未验项。
- 变更超过 30 行时完成 Antigravity 与 Claude 双模型审查，Critical 修复后重审。
