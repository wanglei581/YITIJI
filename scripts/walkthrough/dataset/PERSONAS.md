# 走查数据集 v2：人设、场景与造数规则（2026-09-29）

产品负责人 9/29：模拟数据也要最贴近实际的工作和生活环境，不是为了测试而造。本文件是数据集 v2 的规格，
由走查窗口定、Grok 批量实现、Codex 与 agy 成对挑「哪里不像真的」、走查窗口验收。之后四端复走都用这一套。

## 0. 三条底线

1. **全部虚构，不碰真人信息。**
   - 姓名：虚构，但要像真的（含生僻字「堃」「犇」「喆」、少数民族带「·」的姓名、复姓）。不再加「测试·」前缀；改用下面的号段与证件号规则保证可识别。
   - 手机号：只用 `138 0000 0xxx`（13800000000–13800000999），不用其它号段。
   - 身份证号：前 6 位固定 `370200`（青岛市辖区的汇总码，不对应个人签发区），出生日期与人设年龄一致，第 18 位按 GB 11643 校验算出（会出现 X）。
   - 证件照：不用任何真人照片；用插画头像或灰色剪影，图上角标「示例」。
   - 公司名：虚构，统一用「青岛某某」结构（如「青岛海湾某物流有限公司」），不借用真实企业名。
2. **真实政策、真实机构的事实：** 要么照公开原文并注明出处链接和日期，要么明确标「示例」。不编补贴金额，不写成某机构背书。机构名一律用「示例·崂山区零工之家」这类带「示例」的名称。
3. **数据走正常渠道产生：** 后台界面建、机构发布、用户在一体机或小程序实际操作、脚本调公开接口。不直接写库。唯一例外须写明原因并经总指挥同意（见 §5 时间）。

## 3. 物（素材，Grok 生成，放 `~/.cache/walk0929/dataset/files/`，生成脚本进仓库 `scripts/walkthrough/dataset/`）

- 简历要乱：招聘网站导出的 Word（多余页眉页脚、奇怪编号）、表格排版、带证件照（示例头像）、空白期、错别字、中英混排、2–4 页不等；PDF 有文字型、有扫描型（图片 PDF）、有加密 PDF、有 40–60 页的大扫描件。
- 格式要现实：.docx、.doc、.wps、.et（WPS 表格）、.pdf、.jpg、iPhone 的 .heic（用 `sips` 转出真实 HEIC）、微信转出的乱码文件名、超长文件名、同名不同版本。
- 身份证正反面：示例样张（大字「示例 非真实证件」），证件号按 §0 规则，末位含 X 的至少 3 张。
- 政策：机构发布的政策公告 12–20 条，分属 4 个机构；能找到公开原文的（青岛市人社局等政府网站），照原文摘要并写出处链接和发布日期；找不到的标「示例」且不写金额。含已过期、已下架、待审核的。
- 官方渠道：每个机构 1–3 条（公众号、小程序、官网），链接用 example.com 子域并标「示例」。

## 4. 场景（要覆盖到，每条写成可执行脚本或人工步骤，并记流水）

高峰排队轮流用机；同一网点共用出口 IP 撞限流；断网（前端离线、API 500）；缺纸、卡纸、粉量低、Agent 离线；用户走开导致超时清场；晚上手机上传、第二天去机器取件；家人代取；取件码过期；作废重发；AI 挂了（超时、被拦）；Word 无转换引擎；加密 PDF；超大文件；做到一半放弃；换人没点结束。

## 5. 量与时间

- 两周铺开：9/16–9/29，工作日多、周末少，上午 9–11 点与下午 2–4 点两个高峰；零工之家早 7–9 点；每天每台 5–40 单不等；约 8% 失败、10% 放弃、5% 过期。
- **怎么产生历史时间（待总指挥确认）：** 正常渠道只能产生「现在」的时间。方案 A（首选）：另起一个「时钟偏移」的 API 实例（Node 启动时注入 Date 偏移，同一个 PostgreSQL），逐天回放用户操作，配套各网点的模拟 Agent；先验证 Prisma 写入的 createdAt/paidAt 确实跟着偏移，验证不过就放弃 A。方案 B（兜底）：历史部分用标注清楚的回填脚本直接写库（每行打 `walk-backfill` 标记），需总指挥同意后才做。今天及以后的数据一律走方案 A 以外的正常渠道实时产生。
- **岗位与招聘会：** 第一次发布是托管 a（我们云上不存岗位、招聘会、企业），正常渠道写入会被 403 拒绝。按青岛七区造的岗位与招聘会（几百条、十几个来源、薪资区间、学历、五险一金、过期下架、来源机构、同步时间、外部 ID）**只在单独的「私有化部署 b」走查栈里造**（`RECRUITMENT_CONTENT_HOSTING_ENABLED=true`，独立库与端口），不进第一次发布这套数据。是否要建 b 栈由总指挥定。

## 6. 验收（走查窗口）

- 抽 10 个人设，逐个看流水是否像这个人会做的事。
- 后台与机构端统计不再是 0 或只有一页：订单两周曲线、各网点差异、失败与放弃占比。
- Codex 与 agy 各出一份「哪里不像真的」，走查窗口裁定。
