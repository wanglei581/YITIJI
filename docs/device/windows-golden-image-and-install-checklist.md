# Windows 一体机 · 母盘镜像清单与现场装机 Checklist（一页纸）

> 2026-09-05 首版。适用对象：现场安装人员（不需要懂代码）。上位文档：[production-agent-onboarding.md](production-agent-onboarding.md)（安装脚本参数）、[windows-host-acceptance-runbook.md](windows-host-acceptance-runbook.md)（真机验收）、[terminal-fleet-management-design.md](terminal-fleet-management-design.md)（批量与换机）。
> 硬规则：绑定码、桥接令牌、任何 token **只在提示框里输入**，不写进命令、工单、聊天、截图。安装包必须来自受控发布的签名 EXE/MSI，不从 Git 检出目录运行。

## A. 母盘镜像（做一次，之后每台机器刷同一份）

| # | 项目 | 要求 | 验证方式 |
|---|---|---|---|
| A1 | 系统 | Windows 10 x64 21H2+ 或 Windows 11 x64（优先 IoT/LTSC 长期版），已激活 | `winver` |
| A2 | 时区与时间 | `Asia/Shanghai`，时间同步开启 | `Get-TimeZone`；与手机时间差 < 1 分钟 |
| A3 | 账号 | 一个本地标准账号自动登录（不是管理员）；管理员账号另设强密码，仅维护用 | 重启后不输密码直接进桌面 |
| A4 | 电源 | 永不休眠、永不关屏、来电自动开机（BIOS）、关闭快速启动 | 拔电再上电能自启到桌面 |
| A5 | Windows 更新 | 使用时段 08:00–22:00 内不重启；关闭「自动重启通知」 | 更新设置页截图 |
| A6 | 打印机驱动 | 预装奔图驱动，驱动识别名固定（真机确认为 `Pantum CM2800ADN Series`），设为默认打印机，纸张 A4，双面单元已启用 | `Get-Printer` 能列出该名称；打印测试页出纸 |
| A7 | 浏览器 | 只需预装 Edge（或 Chrome）并完成一次首次运行；**全屏自启与崩溃拉起由安装包的 Kiosk 看门狗负责**（绑定向导自动注册计划任务 `AIJobPrintKioskWatchdog`，控制中心可查看/停用），镜像里不要再手工配 kiosk 快捷方式或启动项 | B7 重启后自动进入全屏首页，无地址栏；手动关掉 Edge 5 秒内自动回来 |
| A8 | 触控与显示 | 27 寸竖屏 1080×1920，缩放 100%，触控校准完成，屏幕方向锁定 | 四角点击命中；首页舞台无缩放黑边 |
| A9 | 外设 | 扫码器为 HID 键盘模式并以 Enter 结尾；扫描目录 `C:\AIJobPrint\scan-inbox` 已建且仅 SYSTEM/Administrators 可写；U 盘自动播放关闭 | 扫一枚码进记事本能回车；插 U 盘不弹窗 |
| A10 | 网络 | 有线网口；能访问生产 API 域名与 Kiosk 域名（443）；打印机 USB 或同网段有线 | `Test-NetConnection <域名> -Port 443` |
| A11 | 安全 | 关闭远程桌面与远程协助；本地防火墙只放行 Agent 本地端口 9527 的 127.0.0.1；禁用来宾账号 | 外部机器无法 RDP |
| A12 | 清场 | 删除示例文件、浏览器历史、桌面图标；桌面只留「设备绑定」快捷方式（指向安装目录 `provision-terminal.cmd`） | 桌面截图 |
| A13 | 固化 | 以上完成后做镜像快照，记录镜像版本号与日期；后续改动先改镜像再刷机 | 镜像清单登记 |

## B. 现场装机 Checklist（每台机器一遍，目标 15 分钟）

**装机前（后台，1 分钟）**
- [ ] B1 在管理员后台「设备 · 终端」预创建终端：终端编码（如 `KSK-012`）、站点名称、所属机构，生成**一次性绑定码**（有效期内使用，一码一机）。
- [ ] B2 在后台记下该终端的绑定码有效期与站点，不把绑定码发到聊天工具。

**现场（12 分钟）**
- [ ] B3 刷母盘镜像（A13 登记的版本），开机自动进入桌面。
- [ ] B4 连好电源、网线、打印机 USB/网线、扫码器；打印机开机并有纸。
- [ ] B5 运行签名安装包（EXE），保持默认目录；安装结束服务 `AIJobPrintAgent` 应处于「正在运行」。
- [ ] B6 双击桌面「设备绑定」（`provision-terminal.cmd`）：按序号选择打印机（必须与 A6 名称一致）→ 在提示框输入绑定码 → 等待「心跳在线」提示。如需 U 盘/扫码桥接，在同一向导里输入桥接令牌。
- [ ] B7 重启一次。验证：自动登录 → Edge 全屏进入 Kiosk 首页 → 顶栏显示本机终端编码与「打印机在线」。
- [ ] B8 现场三步实测：用手机扫码上传一页 PDF → 走完确认与支付（免费/测试价）→ 真实出纸；再做一次扫描原件 → 结果页显示真实文件。
- [ ] B9 在后台「设备机队」确认该终端：在线、版本号与发布计划一致、无告警。

**交付（2 分钟）**
- [ ] B10 填写装机记录：终端编码、站点、镜像版本、安装包版本、打印机序列号、出纸照片、验收人。
- [ ] B11 把桌面「设备绑定」快捷方式保留（换机/重绑时用），管理员账号密码交给站点负责人保管，不留在机器上。

## C. 出问题先看这里

| 现象 | 先查 | 不要做 |
|---|---|---|
| 首页顶栏显示「未配置终端」 | Agent 服务是否运行；本地端口 9527 是否被占；重新运行「设备绑定」 | 不要在 URL 里手填终端编码 |
| 后台显示离线但机器在用 | 网线/DNS；`Test-NetConnection` API 域名 443 | 不要重装系统 |
| 「打印机离线」 | 打印机电源与 USB；`Get-Printer` 名称是否与 A6 一致 | 不要改驱动名 |
| 绑定码提示无效 | 是否过期、是否已被另一台用过；到后台重新生成 | 不要把旧码发到群里 |
| Edge 白屏或退出全屏 | 看门狗是否在跑；手动重启 Edge | 不要退出 Kiosk 模式给用户用 |

> 换机（同一终端身份迁到新主机）与批量升级/回滚不在本页：按 `terminal-fleet-management-design.md` 的 F2/F3 流程，未落地前换机须先在后台停用旧终端并确认无在途打印任务。
