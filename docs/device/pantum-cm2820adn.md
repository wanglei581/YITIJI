## 五、打印集成方案

### 主方案：Windows 本地驱动（Phase 8.1 当前）

- Terminal Agent 拉取打印任务
- 下载文件到本地临时目录
- 调用 Windows 打印 API，指定 `"Pantum CM2800ADN Series"` 打印机
- 打印完成后上报状态

### 后续扩展：PantumCloudDispatchProvider

未来如厂家开放云打印能力，在后端 `services/print/` 层实现 PantumCloudDispatchProvider。
详细设计见 [windows-terminal-agent-design.md](./windows-terminal-agent-design.md) §PrintProvider 架构。

## 六、开发注意事项

1. **printerName 配置化**：Windows 打印机驱动名称为 `"Pantum CM2800ADN Series"`，不要写死为 CM2820ADN
2. **不要假设 A3**：所有打印功能设计只考虑 A4 及以下
3. **不要假设 WiFi**：设备只有有线网络
4. **不要假设云端扫描 API**：扫描由本地 TWAIN/WIA 或 SMB 目录监听实现
5. **彩色 API 值待确认**：printSetting.mode 的彩色值不得假设为 `"color"`，需厂家确认
6. **测试环境**：开发阶段可用虚拟打印机（PDF 打印机）模拟，上线前必须在真机测试
7. **驱动安装**：部署时需预装 `"Pantum CM2800ADN Series"` 驱动程序

## 七、现场网络部署口径

### 推荐主路径：USB 打印、随身 WiFi 上网

- Windows 一体机通过随身 WiFi 访问生产 API；不要求公网 IP，也不需要端口映射。
- 打印机通过 USB 直连 Windows，生产打印队列只保留一个 `Pantum CM2800ADN Series` 队列，并核对实际 USB 端口（例如 `USB001`）。
- 打印机网口在不需要网络扫描或设备管理时保持不接入，避免 USB 队列和 TCP/IP 队列同时参与打印。

### 需要使用打印机网口时：独立无网关内网

- Windows 有线网卡与打印机网口接入独立小交换机；该网卡只用于打印机内网通信。
- 示例地址：Windows `192.168.50.1/24`，打印机 `192.168.50.2/24`；两端不填写默认网关和 DNS，Windows 默认上网路由继续走随身 WiFi。
- 打印机不直接接入公网，不在随身 WiFi 上暴露管理端口，不启用 Windows 网络桥接或 Internet Connection Sharing。
- USB 与网口不得为同一台机器各建一个生产打印队列；必须明确一个主打印端口，另一条链路只服务于经验证的扫描或管理用途。

### 每台设备交付前必须复验

- 随身 WiFi 自动重连、Windows 重启后 Agent 自动启动、打印机断电重启后状态恢复。
- Agent 只监听 `127.0.0.1:9527`，云端通过 HTTPS 心跳；后台显示终端在线、打印机 `ready`。
- 记录终端编号、打印机驱动名称、USB/TCP 连接方式、局域网地址（如有）和 Agent 版本；每台设备单独绑定凭证，不复制另一台设备的 token 或系统镜像。

## 八、面板功能与规格（据中文用户指南 V1.4，2026-09-29 补）

> 手册是 CM2800 系列通用本（p90 注明各型号规格略有差异）。页码为 PDF 页序（印刷页码 = PDF 页 − 20）。凡标「待现场核实」的，以本机铭牌和面板实物为准。

### 面板功能

- 主屏第一页四个入口：复印、扫描、**身份证复印**、**票据复印**；身份证复印可调色彩、排列方式、明暗度、纸张尺寸、自动纠偏（p45、p50）。证件放哪、怎么翻面手册没写，**待现场核实**。
- 自动输稿器**只扫一面**：双面原件要把原件原样放回输稿器再过一遍，面板等不到就只印单面（p48–49）。
- **上一位用户调过的明暗度、纸张等设置会留给下一位**（p46）——每日开门检查要把面板复印设置恢复默认。
- 电源键在面板右侧：**短按只进节能，按住超过 2 秒才关机**；电源灯闪烁 = 休眠，不是故障（p23、p25）。约 1 分钟无任务自动休眠（p10、p90）。
- 前置 USB 口在面板左侧，手册只写了「扫描到 U 盘」：只认 **FAT / FAT32**，文件存进 U 盘里的 `PantumScan` 文件夹（p21、p55）。**U 盘直接打印手册里没有，待现场核实**。
- 面板推扫格式：PDF、PDF/A、TIFF、JPEG、OFD，**没有 PNG**（p53）；PNG 只在电脑端扫描软件里有（p52）。Agent 扫描监听只认 pdf/jpg/jpeg/png，面板选 TIFF / OFD 会怎样**待现场核实**。
- 扫到 SMB 要先在网页管理里配 SMB 地址簿（p39、p54）。
- 电脑端可经 USB 用 **TWAIN / WIA** 发起扫描（p51），「屏幕一点即扫」有硬件依据（排在第一次发布之后）。

### 网页管理（EWS，p39）

- 打印机接网后在浏览器输打印机 IP 进入。第一次登录或恢复出厂后，先输产品序列号，再设用户名和密码（密码 ≥8 位，含字母、数字、特殊字符）。账号口令只进密码库。
- 「产品信息」页能看四色粉盒状态、废粉瓶状态、打印机状态；机器设置里有 SMB 地址簿、电子邮件通知、固件升级、日志导出。「协议设置」里有没有 SNMP、「电子邮件通知」能不能发缺纸 / 卡纸，**待现场核实**。
- 取不到 DHCP 时会落到 169.254.x.x，独立内网要先手动设固定地址（p36、p81）。

### 安装与供电安全

- 插头要放在伸手能拔的位置（奔图 CM2800 系列用户指南 V1.4 第 4 页，PDF 页码）。
- 手册禁止对本机使用延长线、多引线电源板、多引线扩展器或 UPS，也禁止与内联浪涌保护器一起使用（奔图 CM2800 系列用户指南 V1.4 第 6 页，PDF 页码）。插座要正确接地；本机是 I 类设备，必须接带保护接地的插座（奔图 CM2800 系列用户指南 V1.4 第 6、10 页，PDF 页码）。
- 机顶不放任何东西；远离空调、暖气和通风管道（奔图 CM2800 系列用户指南 V1.4 第 9 页，PDF 页码）。
- 机柜据此：打印机单独直插接地的墙插，柜体只留走线孔和拔插空间；多孔插排和 PDU 按多引线电源板处理，只给主机和屏幕用（母盘清单 F 段已同步，2026-09-29）。

### 真机核实清单（下次人在机器旁逐项记回执）

下面 6 项手册没写清、或本机型号与系列规格可能有差异，下一次到机器旁时逐项核实，结果记回 `docs/progress/current-progress.md`；核实前不得按假设开发：

1. **U 盘能不能直接打印**：手册只写了「扫描到 U 盘」（奔图 CM2800 系列用户指南 V1.4 第 21、55 页，PDF 页码），U 盘直接打印手册里没有——插 FAT/FAT32 U 盘，看面板有没有直接打印入口。
2. **本机有没有 Wi-Fi**：系列规格含 802.11a/b/g/n 与低功耗蓝牙（奔图 CM2800 系列用户指南 V1.4 第 14、91 页，PDF 页码），本机以铭牌为准。
3. **网页管理「协议设置」里有没有 SNMP**；「电子邮件通知」能不能配置缺纸、卡纸事件通知（奔图 CM2800 系列用户指南 V1.4 第 39 页，PDF 页码）。
4. **身份证复印的证件放置与翻面**：手册给了可调参数（奔图 CM2800 系列用户指南 V1.4 第 45、50 页，PDF 页码），证件放哪、怎么翻面没写。
5. **面板选 TIFF / OFD 扫描时 Agent 怎么处理**：Agent 扫描监听只认 pdf/jpg/jpeg/png，面板推扫格式没有 PNG（奔图 CM2800 系列用户指南 V1.4 第 53 页，PDF 页码）。
6. **面板设置能不能自动恢复默认**：手册写明上一位用户的明暗度、纸张设置会留给下一位（奔图 CM2800 系列用户指南 V1.4 第 46 页，PDF 页码；画质、缩放同时出现在「一直生效」和「恢复默认」两句里，这两项不按会留下写）；若面板有「任务结束恢复默认」类选项，现场故障处置单的每日开门检查可以改为配置一次。
