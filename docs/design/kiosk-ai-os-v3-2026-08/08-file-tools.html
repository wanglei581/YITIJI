手写签名的法律效力口径

本机的手写签名是图像合成：把签名图片叠到 PDF 上，不具备《电子签名法》意义上的可靠电子签名效力，也不做时间戳与身份核验。需要法律效力请走线下签署或有资质的第三方 CA。签名图像只用于本次合成，会话结束即删除，不会留在机器上；合成结果是新文件，原件不变。
