## 一、范式（不变）

**旧**：首页摆功能目录 → 用户自己判断问题归类 → 自己填参数 → 自己决定下一步。
**新**：用户带处境来 → 系统翻译成任务链 → AI 给**带理由的下一步** → 用户只做**确认**。

> **AI 承担"想"，用户承担"定"，系统与硬件承担"做"。AI 永不替用户按下不可逆的按钮。**

一体机特有约束（决定形态）：站立、可能排队、停留 3–8 分钟、手不干净、旁边有人。因此自由文本是兜底不是入口；每步只给一个主推荐；建议必须给理由；隐私默认超时清场。

## 二、核心对象：办理单（Errand）

```text
说清处境 / 直接选服务
  → 系统盘点已有材料与缺口
  → AI 给受控建议（动作 + 理由 + 代价 + 备选）
  → 用户确认关键动作
  → 服务端 / 支付 / 硬件真实门控
  → 结果进入本人资产、订单或第三方来源
```

字段：`errandId / intent / goalText / steps[] / assets[] / context / advice / status`。
意图为**封闭集 7 条**：`print / resume / fair / job / interview / policy / unsure`，不做开放域 NLU。
生命周期：90 秒无操作提示，120 秒清空全部本地缓存回待机。**登录门设在「沉淀」这一步，不设在入口。**

## 三、建议层（做不好整套就是花架子）

每条建议四要素齐全，缺一不发：**动作 / 理由 / 代价 / 备选**。

证据分级（**硬约束**）：

| 级别 | 来源 | 措辞权限 |
| --- | --- | --- |
| **E1** | 用户数据事实（页数、缺项、历史订单） | 可陈述、可祈使 |
| **E2** | 系统 / 设备 / 来源事实（彩色可用、今天有场次、截止日） | 可陈述、可祈使 |
| **E3** | 模型判断（表达优劣、匹配感受） | **必须标注「AI 判断，仅供参考」**，不得单独构成主建议 |

无 E1/E2 支撑不得用祈使句。本条只约束**建议层**；界面自身的操作指引（"先选一项服务"）不受此限。
每屏最多 1 条主建议 + 2 条备选。建议不可用时**整块换成「什么不可用、还能做什么」**，不显示空的 AI 壳子。

## 五、四态与失败路径

每页必须成立四态，且**四态同一套版面**：`默认 / 首次使用（无上下文）/ AI 不可用（降级）/ 设备离线`。
不因状态重排页面、不换栅格、不抻长卡片；只换该位置的话与主按钮。

| 故障 | 降级 | 绝不能做 |
| --- | --- | --- |
| AI 不可用 | 退目录模式，业务不阻断 | 空建议卡 / 假建议 |
| OCR 置信度低 | 标注需人工复核，**不送 LLM** | 用低置信文本出结论 |
| 打印机离线 / 缺纸 | 改为"转存我的文档"或换机取件 | 显示"设备正常" |
| 支付成功但打印失败 | 待打印订单 + 取件码，可换机复打；不打了按**未出面数**退款 | 静默失败 |
| 会话超时 | 凭手机号找回未完成办理单 | 丢弃已付费任务 |
| 不满意 AI 结果 | 版本列表可回退 | 覆盖原件 |

### 5.1 第三条轴：收银处境（`data-pay`，只有 P06 用）

钱的界面不能只有"成功/失败"两态。P06 第 5 站「收银」有**七种处境**，
和四态、阶段一样走 `window.v3ApplyVisibility()` 统一判定，三条轴都命中才显示：

| `data-pay` | 处境 | 关键约束 |
| --- | --- | --- |
| `wait` | 屏上出码，等用户扫 | 码有失效时间；失效即作废，不能两个码都能付 |
| `scan` | 本机扫用户付款码 | 只读一次，不保存用户付款码 |
| `confirm` | 已扫到，等渠道回传 | **明确写"不要重复支付"**；重复到账自动退回原路 |
| `paid` | 已到账 | **付款不等于自动开印**，仍需用户按「开始出纸」 |
| `expired` | 码已失效并作废 | 重新出码同时关闭旧码；这笔钱没扣 |
| `query` | 主动查单 | 三种结果都写明；结论标 `E2 来自支付渠道`，本机不替渠道下结论 |
| `closed` | 超时关单 | **没收钱也没打印**；码同步作废 |

### 5.2 第四条轴：任务处境（`data-job`，只有 P06 用）

**「已支付」到「纸出来」不是一步。** 原来 S6 一进来就是"出纸中 3/15 面"，
用户卡在排队时会以为机器死了，然后重复付款、拍机器、找人。六个处境：

| `data-job` | 处境 | 关键约束 |
| --- | --- | --- |
| `queued` | 排队中 | 钱已收不重复收；可离开凭码回来打；超 10 分钟自动转待打印 |
| `checking` | 服务端校验 | 页数/字体内嵌/加密/幅面。**宁可现在拦住，不要出到第 7 页才发现字体丢了** |
| `checkfail` | 校验未通过 | 一张纸没出、已原路退款；两条路：换文件 / 让本机转成可打印 PDF |
| `printing` | 正在出纸 | 已开始的这一份不可取消 |
| `jam` | 卡纸暂停 | 剩余份数保留，可换机续打 |
| `timeout` | 10 分钟超时 | 转待打印订单，钱不退也不重复收；不打可按未出面数退 |

这条轴最重要的作用是**堵住伪造状态**：右栏「状态 / 已完成 / 支付」三行必须跟着处境走。
校验失败时还写「正在出纸 · 已完成 3/15 面 · 已支付」，就是 §9 明令禁止的伪造能力。

铁律两条，写在 `styles/pay.css` 顶部：
① **同版面切换** —— 金额位、码位、状态行位置永不移动，只换字与色；收银界面一跳版式，用户立刻怀疑自己付错了。
② **金额不做任何动效** —— 没有 count-up、没有渐显、没有骨架屏；一个正在变化的数字会被读成"还没算完"或"又涨价了"。

收银台只用状态语义色（jade 已到账 / amber 等待 / coral 不可逆或已关单），
**身份色 `--cat-*` 不进收银台** —— 这里表达的是状态，不是服务种类。

页面里那条虚线小控件条带 `data-review`：它是**原型评审脚手架**（用来切到某个处境），
不是产品 UI，自检的触控尺寸与文字裁切检查会跳过它。**产品 UI 一律不许挂这个属性。**

## 六、视觉与构图基线（本轮新定）

### 6.1 配色

默认主题 **`warm` 暖玉纸**：象牙纸底 + 深青玉主色 + 铜金辅色。
`styles/themes.css` 提供 9 套主题（warm / honey / frost / amber / jade / cobalt / neon / pine / ink），任何页面加 `data-theme` 即整套切换。

**两套色永不混用**：

- **状态语义色**：青玉＝本机服务与已验证 / 钴蓝＝第三方与官方来源 / 琥珀＝待核实 / 朱砂＝需本人确认的不可逆动作。只出现在状态点、标签、按钮。
- **服务身份色**（`--cat-*`）：松青 打印 / 铜金 简历 / 靛蓝 岗位 / 赤陶 招聘会 / 湖青 面试 / 石板蓝 政策。只出现在服务入口色块与图标底。

**刻意不设紫色 / 靛紫**——紫蓝渐变是当前 AI 产品的通用皮，用了就落进"AI 味"。

### 6.2 构图三条

1. **纵深靠重叠与投影**，不靠更多描边：玻璃指令胶囊用负边距跨在色域版头底边上。
2. **玻璃只浮在大图或色域之上**，纯色底不用玻璃（会显脏）。
3. **比例由任务决定**，不由组件默认值决定：入口刻意不等宽，文件类页面预览占 55–65%。

### 6.3 竖屏分区（全站强制）

```text
  0 ─  100px   顶栏：品牌 / 设备 / 时间        只看不摸
100 ─ 1688px   内容主体（唯一滚动容器）        视线自然落点
1688─ 1812px   ActionBar 常驻，主按钮恒定右下  手的舒适落点
1812─ 1920px   底部导航：首页 / AI 顾问 / 我的
```

主按钮 ≥64px 高，可点击目标 ≥48px，ActionBar 不参与滚动。

### 6.4 动效纪律

每个效果必须能说出它在表达什么，否则不做：

| 效果 | 含义 |
| --- | --- |
| 数据流连线 | 顾问 → 你的指令 → 排出的路径是一条链 |
| 路径流光 / 节点光环 | 办理方向；当前这步是活的 |
| 玻璃反光跟手 / 按压微倾斜 | 触点反馈（一体机没有鼠标） |
| 计数点阵 | 真实数量（12 个点 = 12 家来源） |
| 系统脉搏线 | 终端每 5 秒上报一次 |
| 处理日志 | AI 此刻在读什么、核对什么（不是转圈圈） |
| 启动序列 | 系统开机，不是网页加载 |

**禁用**：紫蓝渐变 / 发光星星 / 魔法棒图标；**数字滚动**（中间值会被当成真实读数，等于伪造数据）；语音波形（本机没有语音下单能力）；粒子雨星空（纯装饰且吃 GPU）。

只动 `transform / opacity / filter`。`prefers-reduced-motion` 全部退化；`html.lowgpu` 关闭模糊与色域动画。

### 6.5 文件与令牌

```text
styles/tokens.css      设计令牌唯一来源（色/圆角/间距/字号/动效/分区）
styles/themes.css      9 套配色主题
styles/base.css        舞台 / 极光 / 颗粒 / 顶栏 / ActionBar / 导航
styles/components.css  公共组件（panel / btn / chip / ev / dot / tile / advisor / kv / notice…）
styles/vivid.css       V5 构图层（色域版头 / 玻璃胶囊 / 身份色卡 / 横向路径 / 仪表）
styles/fx.css fx2.css  动效层
scripts/sprite.js      图标库（24×24 / stroke 1.75 / 内联 symbol 注入）
scripts/stage.js       工作台外壳 + 四态切换 + 自查
scripts/fx.js fx2.js   动效行为
```

**token 化强制**：色值、圆角、间距、字号、动效时长一律走变量，禁止硬编码。同名组件全站一种长相。
**零外部依赖**：无 CDN / 远程字体 / 远程图片，断网可渲染。

## 九、验收口径（每页交付前必须过）

分两部分：**机器能判的十项**跑 `verify.html`，**机器判不了的**逐条人工过。
不要把人工那部分当成"看一眼截图就行"——首页那批文字裁切，肉眼只看出 1 处，机器抓出 6 处。

### 9.1 机器判定的十项（`verify.html` 全量自检）

跑法：`verify.html` → 开始全量自检。它逐页在 1080×1920 iframe 里遍历
**每个阶段 × 四态**（P06 额外遍历收银七处境与免费单分叉），调页面内置的 `window.v3Audit()`。
只列不通过的组合，全绿说明这一轮改动没引入回归。

| # | 检查项 | 判据 | 为什么机器来判 |
| --- | --- | --- | --- |
| 1 | 主体纵向溢出 | `= 0` | 内容被 `overflow:hidden` 悄悄切掉，肉眼看不出 |
| 2 | 横向溢出 | `= 0` | 装饰层刻意出血已排除，剩下的都是真问题 |
| 3 | 触控 < 48px | `= 0` | 预览有缩放，用眼估尺寸一定错 |
| 4 | 文字裁切 | `= 0` | 量文本节点自身矩形，不看 `scrollWidth`（伪元素会污染） |
| 5 | 违禁文案 | `= 0` | 允许否定式声明（见下） |
| 6 | 量化红线 | `= 0` | 禁百分比匹配度、禁录用概率；进度百分比不误报 |
| 7 | 建议无证据标注 | `= 0` | 出现「我建议/建议先/推测」等建议措辞，页面必须有 `.ev--e1/e2/e3`。**该标 E2 还是 E3 属人工项** —— 「建议先把要打的打了，打印不依赖网络」依据是设备能力事实，标 E2；「这段表达偏弱」是模型判断，必须 E3 |
| 8 | 来源三字段缺失 | `= 0` | 展示第三方条目就必须有 来源机构 / 同步时间 / 外部 ID |
| 9 | 四态未落地 | `ok` | 只换 `data-state` 但全页没有一个 `[data-when]` = 四态是假的 |
| 10 | 标点被顶到行首 | `= 0` | 中文排版禁则。渲染后按字符量、**跨元素边界**连续比较 |

第 5 项**允许否定式声明**：「本机不代收简历」「不预测录用概率」这类合规披露必须能写，
否则页面会被逼着回避这些词、反而说不清边界；肯定式用法仍然必抓（已做反向验证）。
否定词必须和被检词**在同一个文本节点里**——曾经踩过：表格左列写「简历代收」、右列写「不支持」，
检查器只看到左列，照样报违禁。

`[data-review]` 是原型评审脚手架（切处境、切态的虚线小控件），第 3、4 项会跳过它。
**产品 UI 一律不许挂这个属性。**

### 9.2 机器判不了、必须人工过的

1. **四态同一套版面** —— 机器只能判"有没有做四态"，判不了"版面有没有跳"。
   要亲自切四态看编排带高度、卡片高度、卡内空白是否基本一致。
2. **建议四要素齐全** —— 动作 / 理由 / 代价 / 备选，缺一条就是花架子；理由要标证据级别。
3. **不伪造能力** —— 没有真实数据、接口、硬件状态或保存结果时，不得展示
   已完成 / 已保存 / 已投递 / 已打印 / 设备正常。这条只能读文案判断。
4. **孤字** —— 「报告可打\n印」这种掉一个字到第二行，不触发任何检查，只能看。
   （**标点被顶到行首已归机器**，见 9.1 第 10 项：源码里 grep「`</b>，`」没有意义，
   那种写法极常见，只有断行恰好落在标点前才出问题，而且只在跨元素边界时才会发生。）
5. **主按钮 ≥64px、ActionBar 主按钮恒定右下**；文件类页面预览占视觉主体 55–65%，
   多页可翻页并显示「第 X / 共 Y 页」。
6. **零外部依赖，断网可渲染**；`prefers-reduced-motion` 下动效退化。
7. **金额与状态数字禁动效** —— count-up 会把 78% 显示成中途的 22%，被读成"还没算完"。
8. **归属 ≠ 承接** —— 对着 [coverage-audit.md](coverage-audit.md) 核这一页认领的原型编号，
   逐条问"旧屏那个功能点在新页哪里"，而不是"这一页看起来完整吗"。

**本机 Codex 调用注意两点（2026-08-08 踩过，后续别再踩）**：

1. **必须重定向 stdin**：`codex exec ... < /dev/null`。否则它会一直等 stdin 关闭而**静默挂住**，
   输出 0 字节，看起来像在思考——本轮因此空跑 56 分钟。
2. **必须用真实二进制路径，不要走 `~/.local/bin/codex` 软链接**。该软链接指向
   `/Applications/ChatGPT.app/Contents/Resources/codex`（codex 随 ChatGPT 桌面端分发），
   而 codex 按 argv[0] 所在目录寻找辅助程序 `codex-code-mode-host`，走软链接时在 `~/.local/bin/`
   找不到，报 `failed to spawn code-mode host`，后果是**它读不到任何文件**、结论没有证据；
   `--disable code_mode` 无效。正确调用（无需重装）：

   ```bash
   /Applications/ChatGPT.app/Contents/Resources/codex exec -s read-only --skip-git-repo-check "<题目>" < /dev/null
   ```
