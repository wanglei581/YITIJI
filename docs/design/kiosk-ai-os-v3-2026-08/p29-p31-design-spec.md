## P29 证件照工作台(29-id-photo.html)

**真实现状(设计必须如实呈现):** 后端零实现;本机无补光/背景板,不做拍摄/抠图/换底色;仅 A4 普通纸,相纸未配置;能力开关 `id_photo` fail-closed。线上仅"即将上线"说明页。

**关键修正(百炼「职业证件照」模板印证)**:上传照片→AI 规格化(裁剪/换底/检测)是**纯软件路径,不依赖本机拍摄硬件**——只有「现场拍摄」需要补光/背景板、「相纸出片」需要相纸。态 B 按"软件先行"设计:后端服务建成即可开放上传路径,拍摄卡与相纸选项单独按硬件到位解锁。

**双态结构(P19/P27 同款诚实模式):**

- **态 A · 当前锁定态(默认)**:「证件照排版尚未开放」+ 真实原因(后端零实现为主因;硬件只挡拍摄与相纸)+ 两条真实替代路径(已有电子证件照→P06 照片打印;纸质→P07 扫描留存)+ 四规格参考表(一寸 25×35 / 小一寸 22×32 / 二寸 35×49 / 小二寸 35×45mm,标注"仅供了解")+ 右栏开放顺序 tline(上传路径先开→硬件分别解锁)。
- **态 B · 开放后流程(常驻「示意·非当前状态」标注)**,阶段:
  1. **s1 选来源**:本机上传 / 手机扫码传照(主路径);「现场拍摄」锁定卡注明硬件未配置
  2. **s2 AI 规格体检**:头部占比(55–65%)/居中度(±5%)/背景色差(≤8%)/分辨率(300dpi),逐项 E1 证据;不合格给具体原因+重传引导,不静默通过
  3. **s3 规格与底色**:四规格 × 白/蓝/红底;换底标 E3「AI 处理,打印前请确认」;简历常用一寸/小二寸提示
  4. **s4 排版预览**:A4 排版(1 寸 8 张 / 2 寸 4 张)真实裁切框示意;相纸以本机配置为准
  5. **s4B 放进简历(用户 2026-08-09 增补)**:选简历(我的简历/本次会话已传)→ AI 识别版面旧照片区域(E1:「第 1 页右上角检测到旧照片 3.2×4.5cm」;无照片给右上/左上/自定义预设插入位)→ 旧/新对比预览、尺寸自适配 → **只生成简历新版本,原件永不覆盖**(权限矩阵),采纳由用户确认 → 进「我的简历」;ai-down 态机械排版不依赖 AI,预设位大按钮照用
  6. **s5 送打印**:真链 06?stage=s3;「预估 · 以打印工作台核价为准」;可同时带上换照后的简历新版本
- **四态**:ai-down=体检/换底不可用、合格照可直接排版;device-off=可完成到排版,产物存我的文档换机取。
- **反向闭环**:P09 简历诊断新增提示项「简历没有照片/照片不规范 → 去证件照工作台」。

**数据回流**:排版产物→我的文档(短期);订单→打印订单。**合规硬线**:证件照=敏感文件(签名 URL ≤30min、TTL 清理、删除留日志);「采集→使用→删除→审计」全链;公共终端不落前端存储。

**上线依赖(Codex/W5)**:规格校验服务→换底服务→排版 PDF→简历照片区域识别与替换→`id_photo` 开关 available→真机验收。

## P30 岗位大师 · 决策台(P11 升格,不新增第二入口)

**IA 裁决沿用 2026-07-11 用户拍板**:唯一入口 `/resume/job-fit`;「岗位大师」是 P11 完全体,文件仍为 11-jobfit-compare.html,页名改「岗位大师 · 决策台」。

**能力底盘(PR #117 已验证实现,M1+M1.5 七块):**
1. 适配度三档(reference_high/medium/low,禁百分比)+ matchedSkills[技能,简历原文证据] + gapSkills[技能,建议] + 综合理由一句(E3)
2. 关键词覆盖:命中词强制出自简历原文(E1),缺失词来自 JD(E2);无比例数字
3. 差距行动卡:每 gap 配 learningDirection + firstStep(今天就能做的第一步)
4. 简历改写建议(0–5 条,E3;出口「带去简历工作台逐条改」→09?stage=s4)
5. 面试预测(0–4 条:问题+为什么问+准备提示;明示"不是考官题库")
6. 晋升路径三节点(现在→1–3 年→3–5 年,各带 rationale+firstStep;整块 E3、"不是承诺")
7. 风险标注(硬门槛/信息完整度,三档 label+reason+basis;"信息不足≠不会")

**增量(M2/M3 精选 + 百炼借鉴):**
8. 多岗对比(≤3,独立阶段):并排三档+各自 top 差距;来源=情报台收藏或手输 JD 文本(外部 URL 只作参考文本不入库);「查看岗位」「去来源平台 · 扫码投递」独立按钮;仅本人可见不回传企业
9. ATS 机读友好度引用卡(完整诊断在 P09,本页引用)
10. 方向缺口 + 站内薪资参考:站内聚合 E2;样本<5 显示「样本不足」;来源方薪资原样转录;**永不预测个人薪资**
11. RIASEC 兴趣快测冷启动:first 态链 P28,本页不重复建测评

**带走报告**:A4 三页(AIGC 标识封面+免责+来源三字段 / 三档正文+差距第一步+风险薪资 / 追问清单页+固定页脚);打印真链 06?stage=s3 预估口径;去向=我的文档+AI 服务记录+打印订单,不去任何企业。

**四态**:first→引导 09/28;ai-down→只留岗位原文+历史记录,"结论造不出来就不出";device-off→报告可存不可打。
**措辞注意**:检测器把非否定式连写「平台投递」判违禁——按钮写「去来源平台 · 扫码投递」(两个白名单短语)。

## P31 签约风险提示(31-contract-review.html,用户可见名不含"审查")

**真实底盘(已实现,默认关)**:三步流程+状态机+consent 快照哈希+PII 脱敏+安全门;报告端点 501;入口=AI简历服务→签约与权益;Gate 0 六项发布门禁 production_default=false。

- **s0 锁定态(默认·真实)**:Gate 0 六项可视化(境内模型 allowlist/算法备案/生成式 AI 安全评估/AIGC 可见+元数据双标识/法务黄金集,逐项 chip--info「待完成」)+ "为什么还不能用"信任化解释 + 真实状态 kv(开关关闭/已收合同 0 份/入口位置)
- **s1 上传与知情**:合同文件(pdf/doc/docx/图片 ≤20MB)+ **五类型**(2026-08-10 用户增补第 5 类):
  1. 劳动合同 2. 实习协议 3. 竞业限制协议 4. 录用通知书(以上四类=专项规则包,对应真实 ContractType 四值)
  5. **其他合同(通用)**——新增:非上述四类的合同走**通用维度审查**,八维度:主体资格/合同期限/费用与支付/违约责任/解除与终止条件/争议解决/权利义务对等性/格式条款风险;卡面如实标注「通用维度覆盖较宽,针对性弱于专项类型;劳动相关合同请优先选专项类型」;落地=新增 ContractType `generic` + 通用规则包(Codex W6 范围)
  + 14 类条款范围 chips(专项)/八维度 chips(通用,随类型切换)+ 知情同意五项逐条披露必勾选(目的方式/数据类别/受托方/最长保存 2 小时/主体权利)
- **s2 提取确认**:五阶段进度(OCR→确认→规则→AI→安全门,只报阶段与页数**无百分比**)+ 确认弹层(页数/质量三档/类型)+ 低置信红警 + 随时取消并删除
- **s3 三档风险结果**:优先核查/关注/信息不足;FindingCard=原文摘录(页码)→说明→法律依据→局限性→建议追问;**通用合同的 finding 按八维度分组标注维度名**;截断黄条;AIGC 标识常驻;零风险诚实空态(不说"合同安全")
- **s4 报告打印**:A4 三页(AIGC 封面+免责+版本三元组 / 三档正文[通用合同带维度栏] / 追问清单独立页);打完即删;真链 06?stage=s3
- **常见签约问题**:8 条静态参考(试用期/社保/违约金/竞业/押金证件/加班费/Offer 撤回…)逐条标法规依据+更新时间 E2;现在就真实可用;不做自由输入闲聊
- **四态**:ai-down=不可发起、已有结果可看;device-off=可全流程、报告存文档换机打。固定免责「仅作风险提示,不构成法律意见」常驻。
