STAR：讲经历的四段结构 通用方法
S 情境 Situation 简述事件发生的背景，遇到了什么问题或挑战。
T 任务 Task 明确你在这个情境中需要完成的目标或承担的角色。
A 行动 Action 详细描述你为了达成目标采取了哪些具体的行动步骤，重点突出你自己的能力。
R 结果 Result 说明最终取得了什么成果，尽量用数据说话：提升转化、缩短周期、降低成本、服务人数、完成数量等。
高频问题 · 回答结构 通用准备方法 8 题 · 可上下翻
1请简单自我介绍一下？
考察什么表达能力、重点提炼能力、与岗位的初步匹配
回答结构控制在 2–3 分钟：我是谁 + 我做过什么（核心成绩）+ 我为什么适合这个岗位
常见错误背诵简历逐条复述；讲童年成长经历；超过 5 分钟
提示结尾落到「所以我希望在这个岗位上……」，把话题引向岗位
2你为什么想应聘这个岗位？
考察什么求职动机的真实性、对岗位的理解程度
回答结构岗位职责的理解 + 自己能力的对应点 + 想在岗位上解决或达成什么
常见错误只说「想找份工作」「离家近」；对岗位职责一无所知
提示提前读 3 遍岗位描述，至少能说出两条核心职责
3你最大的优势是什么？
考察什么自我认知，以及优势与岗位的关联度
回答结构一个明确优势 + 一个具体事例支撑 + 与岗位的关联
常见错误罗列五六个空泛形容词（认真、负责、能吃苦）却没有事例
提示优势只讲一两个，但配上能讲细节的真实例子
4你最大的不足是什么？
考察什么自我认知的诚实度、改进意识
回答结构一个真实的、非致命的不足 + 正在采取的改进行动
常见错误说「我太追求完美」这类包装答案；说出岗位核心能力上的硬伤
提示重点在「我正在怎么改」，给出具体行动
5讲一个你解决困难或挫折的经历。
考察什么问题分析、行动力、复盘能力
回答结构用 STAR：背景 → 你的任务 → 具体行动 → 量化结果与收获
常见错误只抱怨困难本身；说不清自己在其中做了什么
提示突出「我」做了什么，而不是「我们团队」做了什么
6你为什么想来我们公司？
考察什么求职诚意、对公司的了解程度
回答结构公司行业地位或业务方向 + 个人职业规划的契合点
常见错误说「贵公司是大公司 / 工资高」；明显没做任何了解
提示至少了解公司主营业务和一条近期动态
7你对薪资有什么期待？
考察什么自我定位是否客观、沟通方式
回答结构给出有依据的区间 + 表达对综合发展的关注 + 留出协商空间
常见错误一口咬死具体数字；完全不敢谈，说「随便都行」
提示先在岗位台看同方向岗位的公示薪资区间，那是来源平台原文；本机不预测你个人能拿多少
8你还有什么想问我们的？
考察什么求职意愿、思考深度，这几乎是必问的收尾题
回答结构准备 2–3 个问题：岗位的工作内容细节 / 团队情况 / 入职后的成长路径
常见错误说「没有问题了」；上来就问加班和假期
提示问「这个岗位前三个月最重要的目标是什么」是稳妥的好问题
自我介绍：三档时长的结构 通用方法
30 秒 我是谁（姓名 + 当前身份） → 一句话核心优势 → 我为什么来应聘这个岗位
1 分钟 我是谁 → 我做过什么（1 个核心成绩） → 我为什么适合这个岗位
3 分钟 我是谁 → 我做过什么（2–3 段经历 + 量化成绩） → 我为什么适合这个岗位 → 我希望在这个岗位解决什么问题
面试是展示自我、与企业双向选择的过程。以上是通用准备建议，标 E2；只有「按目标岗位挑重点」是模型判断，标 E3。 本机不预测录用概率、不给通过率、不做面试打分排名，也不代表用人单位的判断。
