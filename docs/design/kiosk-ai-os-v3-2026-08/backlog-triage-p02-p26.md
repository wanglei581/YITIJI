## 三条要提醒的

### 1. 「免费打印」那条最要紧，且不是设计能定的

`47` 原型写的是**免费**，V3 写的是 0.20 元/页。两者必有一个是错的。

- 若那是主办方或政府买单的活动资料 → **V3 在多收钱**，属于诚实性问题，A 类。
- 若原型当初只是没写价格 → V3 是对的，把这条降级即可。

**这需要问出资方，不是看页面能判的。** 在问清之前，两边都不要照着做。

### 2. P23 的三条（改保留期 / 删文件 / 撤回授权）是同一个问题

V3 的 P23 在**说明**数据怎么处理这件事上做得很足（留/清两栏、删除日志、
管理员能看到什么），但**用户能对自己数据做的操作只有一个：结束并清空**。

知情做到了，控制没做到。这三条补齐才算完整。

### 3. 「意见反馈」是跨页缺口，不是 P23 的单页问题

`backlog-triage-2026-08-09.md` 的 A 单里，P06 也有一条
「`33-print-done` 补完成后异常反馈和使用帮助入口」。

两份清单各自独立得出同一结论 —— **全套 26 页没有任何地方能让用户说
「这里出问题了」**。建议作为一个跨页项统一设计，而不是在两个页面各做一个。
