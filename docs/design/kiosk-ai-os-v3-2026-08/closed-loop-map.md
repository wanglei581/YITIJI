## 二、八域入口契约(「八大功能的入口」怎么解)

首页八大功能:打印扫描 / AI简历服务 / 岗位信息 / 招聘会 / AI面试训练 / 政策服务 / 我的 / AI顾问。

**裁决:不新增"功能菜单页"。每个域的入口 = 该域作业台的第 1 阶段(域首屏)。**
理由:一体机操作路径 ≤3 步(CLAUDE.md §13);菜单页多一跳、不带状态,是桌面站的习惯不是站立触控的习惯。域首屏必须同时做到三件事:①看清这个域能做什么(全部子能力入口);②看到我在这个域的资产/进行中事项;③给一条带理由的 AI 建议(四要素,见 README §三)。

| 域 | 首页主卡落点(域首屏) | 域内子能力与横向入口 | 现状 |
| --- | --- | --- | --- |
| 打印扫描 | **P06-s1 选来源** | 四来源卡(本机/扫码/U盘/纸质)+ 横向入口 → P07 扫描工作台、P08 文件加工台 | s1 已是入口形态;**缺 P07/P08 横向入口,补** |
| AI简历服务 | **P09-s1 简历来源** | 来源(上传/扫描/我的简历)+ 横向入口 → P10 访谈式生成、P11 岗位匹配、P12 材料工厂 | **缺横向入口,补** |
| 岗位信息 | **P13 岗位情报台** | 列表/筛选 + 入口 → P14 详情、P15 企业导览、P16 线下机构 | P13 天然是域枢纽;核查三入口是否齐 |
| 招聘会 | **P17 作战台** | 场次/企业/导览/准备单 + 入口 → P18 校园招聘、P19 智慧校园 | P17 天然是域枢纽;核查两入口是否齐 |
| AI面试训练 | **P20-设置阶段** | 逐题/报告/历史/技巧全在台内 | 单台自洽,不动 |
| 政策服务 | **P21** | 三类政策 + 清单打印 | 单页自洽,不动 |
| 我的 | **P23 资产中心** | 简历/文档/订单/AI记录/收藏/权益(P24)/设置 | 已是枢纽 |
| AI顾问 | **P25 驾驶舱** | 九能力入口 + P26 作业面 | 已是枢纽 |

首页主卡上的子 chip(如「U盘」「纸质扫描」)是**深链**:跳到域首屏并预选该项,不绕过域首屏的形态。

## 三、导航契约(每页从哪来、到哪去、怎么退)

全站三条恒定通路(底导航):首页 / AI顾问(P25)/ 我的(P23)。任何页面任何阶段都能一步回这三处;离开多阶段作业台时,若有未完成办理单,必须弹「保留进度 / 放弃」确认,不静默丢。

```text
P01 首页(意图台)
 ├─ 说处境 → 办理单(README §二)→ 按单跳对应域首屏
 ├─ 打印扫描卡 → P06-s1 ↔ P07 / P08(横向,可互回)
 ├─ AI简历卡  → P09-s1 ↔ P10 / P11 / P12(横向,可互回)
 ├─ 岗位卡    → P13 → P14(详情)→ 扫码/去来源平台(离站确认)
 │                └→ P15(企业)/ P16(线下机构)
 ├─ 招聘会卡  → P17 → P18 / P19;P17 内:场次→企业→导览→准备单→打印
 ├─ 面试卡    → P20(台内五阶段)
 ├─ 政策卡    → P21
 └─ 待机 ← P02;身份门 P03 在「沉淀/支付」时弹出;系统态 P04 全局覆盖;P05 手机接力只承接当前会话
```

回退规则:作业台内「上一步」只在台内退阶段;台外统一回域首屏,再回首页。跳第三方来源一律走**离站确认页**(README §四红线)。

## 五、收钱与出纸的唯一通道

全站**只有 P06 的收银→出纸链有支付与出纸动作**。其他页的「打印」按钮(P09 导出打印、P12 材料打印、P14 岗位详情打印、P17 资料打印、P20 报告打印、P21 清单打印、P22 规划打印)一律=「把该产物作为文件送进 P06,从参数核价阶段继续」。不在各页各造一套收银。
推论:任何页面出现价格,只能是「预估,以核价为准」;设备离线态下所有打印按钮降级为「存入我的文档,换机取回」(P01 device-off 态已示范此话术)。

## 六、AI 介入的统一面孔(全站一个模式)

每个域首屏与关键阶段,AI 出现的方式**只有一种**:README §三 的四要素建议卡(动作/理由/代价/备选)+ E1/E2/E3 证据标注。禁止:无理由的"智能推荐"、不可解释的分数、假装在想的空壳动画。
AI 不可用(ai-down)时:建议卡整块换成「什么不可用、还能做什么」;**本机打印扫描浏览永远可用**。
动效纪律沿用 README §6.4;新增动效只允许表达真实状态(在想/在传/在打印),不做无信息的科技感粒子。
