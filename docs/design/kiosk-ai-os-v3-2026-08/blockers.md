## 上线最可能的三个事故(Codex 判断,作为验收反例)

1. **资金**:扫码付款后卡纸,屏幕说「自动退 1.80 元」,但生产没有真实部分退款 + 单价对不上 → 重复扣款或少退款。
2. **隐私**:伪造 URL 资产 / 跨机接管无原子赢家 / 超时口径不一 → 上一位用户的文件被显示或打印给下一位。
3. **履约**:二维码扫不出、彩色双面真机不工作、写死的「02 号机 / 服务台」现场不存在 → 排队用户集中求助,只能人工停机。
