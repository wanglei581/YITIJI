## 上线最可能的三个事故(作为验收反例)

1. **资金**:扫码付款后卡纸,屏幕说「自动退 1.80 元」,但生产没有真实部分退款 + 单价对不上 → 重复扣款或少退款。
2. **隐私**:伪造 URL 资产 / 跨机接管无原子赢家 / 超时口径不一 → 上一位用户的文件被显示或打印给下一位。
3. **履约**:二维码扫不出、彩色双面真机不工作、写死的「02 号机 / 服务台」现场不存在 → 排队用户集中求助,只能人工停机。

## 定版纪律(针对 A15)

1. 当前所有整改代理收工后,**停止一切设计改动**。
2. 跑 `sh tools/make-pages.sh` 刷新清单,再用 `tools/regress.html` 全量回归。
   **测量环境**:必须走 http(file:// 下读不到子页 DOM)、浏览器标签必须在**前台**
   (后台标签节流定时器,会误判成挂死)、每轮清 localStorage、关缓存。
3. 报告通过后打 tag,该版本即「设计冻结版」,后续改动一律走新一轮。
4. 未经全量回归的页面,不得进入交付集。
