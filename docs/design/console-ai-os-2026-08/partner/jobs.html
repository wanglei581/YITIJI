AI 质检与预审暂时不可用
岗位的增删改查、提审、下架、Excel 导入全部照常——这些不依赖 AI。 暂时看不到的是：质检风险分、提交前预审、AI 改写建议。 「内容健康度」Tab 里 E1 规则那一档全部照常（字段完整度 / 过期 / 薪资异常 / 重复——不调模型）；只有 E3 模型那一档暂停。

落地口径
  • 路由不变，但先拆组件：仍是 /jobs；必须先把 455 行拆成 列表 / 表单 / 详情 / 健康度 四个组件再加 Tab（Codex：不拆会立即越过 500 行阈值）。
  • 规则先行：健康度先出 E1 规则版（复用已有 quality-summary，不调模型、零成本），E3 模型版随后。quality-summary 是确定性元数据检查，不得包装成「AI 质检」。
  • 机构侧 AI 三条硬约束：不对求职者做任何判断 · 不生成招聘承诺（与 Admin 共用违禁词库）· 必须人工采纳才生效。
  • 补 CLAUDE.md §10：岗位详情必须展示来源机构 / 同步时间 / 外部ID / 外部投递链接 / 数据来源说明。
  • 新增端点：POST /partner/ai/content-check、POST /partner/ai/content-polish、GET /partner/health/*。
  • 同一套能力也要覆盖 /companies 与 /policy（Codex 指出本映射只覆盖岗位）；/companies 已 631 行，同样需先拆。
