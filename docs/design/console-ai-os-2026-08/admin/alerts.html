处置闭环

待服务端就绪
商用运营需要的完整闭环：确认 → 指派 → SLA 倒计时 → 处理记录 → 恢复留痕 → 未处理升级。 这些现在做不了，因为告警没有持久实体。原型把它画在这里作为需求登记， 但不放可点击的假按钮——那会让运营以为点了有用。

落地口径
  • 本轮只做 AI 归因聚合（前端 + 一个聚合端点即可），不做处置闭环。
  • 处置闭环是独立的后端立项：先建 Alert 实体与状态机，再谈确认/指派/SLA。 在那之前不放假按钮。
  • AI 只做聚合与归因，不自动处置——重启终端、改派物料都必须人工点击。
