# 一体机 AI 求职操作系统 · 融合版原型（2026-08-07）

> 状态：设计候选，不替代现网 Kiosk；基于 8 月 AI OS 原型（`kiosk-ai-os-prototype-2026-08`）重做。
> 范围：27 寸 1080×1920 竖屏一体机，覆盖 01-78 编号的全部功能去向。
> 视觉方向：青序 LightFlow 蓝白服务台（`docs/superpowers/specs/2026-07-11-service-desk-commercial-ux-migration-design.md`）。

## 一、这版解决什么问题

8 月原型的核心问题是「只是 7 月改版」：AI 停在表面（聊天外壳 / AI 横幅），没有真正进入每个功能，
页面也没有形成完整业务闭环。本版重做原则：

1. **AI 内化为功能支撑，不是页面装饰**：识别、检查、建议、整理、诊断全部作为功能模块出现在对应流程里
   （材料检查、OCR 识别、匹配依据、参会准备单），页面不出现聊天框、AI 图标墙或科幻渐变。
2. **零 AI 味**：布局、排版、按钮位置、操作方式全部遵循用户熟悉的办事台习惯；主操作在右下，
   文件窗口完整显示不截断，触控目标 ≥48px、主按钮 ≥56px。
3. **完整商业闭环**：每个入口都满足四问——从哪个入口进、完成什么操作、产生什么数据、
   在哪个业务页面能继续做什么。所有状态（加载/空态/异常）可切换预览。
4. **来源与合规做进结构**：岗位/招聘会/政策只做来源入口；「去来源平台投递/扫码投递/去来源平台预约/扫码预约」
   是唯一合规按钮文案；金额一律「以现场公示价为准」；不硬编码打印机型号。

## 二、与 8 月原型的差异

| 维度 | 8 月原型 | 融合版 |
| --- | --- | --- |
| 视觉 | 深色顶栏 + 公共服务工作台 | LightFlow 蓝白服务台，明亮可信 |
| AI 呈现 | 独立「AI 顾问」聊天感页面 | AI 能力拆进每个功能（识别/检查/建议/整理） |
| 首页 | 目标输入 + 服务目录 | 目标输入 + 六项定版服务 + 今日任务卡 |
| 打印 | 参数页 + 预览分离 | 文件预览 + 材料检查 + 参数 + 核价同屏工作台 |
| 简历 | 诊断/优化分页 | 来源→识别→诊断→优化→沉淀五步闭环 |
| 状态 | 部分屏有状态层 | 全屏支持加载/空态/异常切换 |
| 冗余页 | 27/28/31/35/43/47/64/69/70/73/76 等保留独立页 | 并入主流程，编号保留为映射 |
| 动效 | 静态为主 | 按压/进入/进度/状态切换动效，尊重 reduced-motion |

## 三、信息架构

- 底部三项：首页 / AI 顾问 / 我的（与定版一致，不新增第四项）。
- 首页六项定版入口：打印扫描、AI 简历服务、岗位信息、招聘会、AI 面试训练、政策服务。
- 百宝箱与智慧校园为后台开关控制的专区，不进入六主入口。
- 62/63 是扫码后的一次性手机接力页，只承接当前一体机会话，不是微信小程序。
- 编号 27/28/31/35/43/47/64/69/70/73/76 等为流程映射页，避免旧编号失联。

## 四、核心闭环（每个入口都有归宿）

| 业务 | 入口 → 操作 → 数据 → 沉淀 → 下一步 |
| --- | --- |
| 文档打印 | 打印扫描 → 上传/预览/材料检查 → 参数核价 → 支付 → 出纸 → 订单+取件码 → 我的打印订单 |
| 纸质扫描 | 打印扫描 → 类型/设置 → 扫描 → 预览 → 保存/识别/打印 → 我的文档 / 简历流程 |
| AI 简历 | 来源与目标 → OCR 识别 → 诊断报告 → 优化/生成/匹配 → 我的简历 + AI 记录 → 打印 |
| 岗位信息 | 列表/企业 → 详情 → 收藏/匹配参考 → 去来源平台投递 → 浏览/收藏/跳转记录 |
| 招聘会 | 列表 → 详情 → 展位企业/导览 → 参会准备单 → 打印 → 我的文档；预约=来源平台 |
| AI 面试 | 设置 → 逐题会话 → 报告 → AI 记录 → 打印/再来一轮 |
| 政策服务 | 列表 → 详情 → 材料清单 → 打印（信息只读） |
| 我的 | 概览 → 简历/文档/订单/收藏/权益 → 对应业务页继续操作 |

## 五、打开方式

```bash
python3 -m http.server 8933 --directory docs/design/kiosk-ai-os-fusion-2026-08
```

浏览器打开 `http://127.0.0.1:8933/index.html`。左侧可按业务筛选 01-78 屏；
右上角切换默认/加载/空态/异常状态；原型内主按钮可沿真实流程跳转。

图标使用 lucide（CDN 加载，原型环境可用）；正式实现时使用项目既有图标体系。

## 六、验证与边界

- 1080×1920 下完成全屏布局与状态切换检查（见仓库验证记录）。
- 可见操作目标 ≥48px，主按钮 ≥56px；无横纵截断、无文本裁切。
- 原型不连接支付、AI、用户数据或打印硬件；所有动态数据必须来自真实接口或硬件上报。
- 仅展示来源入口，不伪造投递、预约或签到结果。
