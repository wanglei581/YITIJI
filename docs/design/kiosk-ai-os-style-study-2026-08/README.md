# 27 寸一体机视觉定调稿 V3

> 状态：3 个核心页面的可交互视觉方向候选，不替代现网 Kiosk，不代表 75 屏已重做完成。

本稿由 Codex 与本地 Claude Fable 5 Max 联合审查后收敛。根据用户提供的墨刀《AI 智慧党建 APP》参考提炼视觉方法，而不是复刻手机界面：

- 保留强品牌场景、赤土红主动作、白色内容承接和清晰任务节奏。
- 舍弃手机比例、党建纹样、单色渐变、聊天气泡和密集小字号。
- 适配 27 寸 1080x1920 竖屏，操作区保持大触控目标和较短视线移动。
- 保留首页六个定版入口与首页 / AI 顾问 / 我的三 Tab。
- 设备、支付、打印和第三方来源继续使用真实状态与明确确认门控。
- 页面编号只存在于原型工作台，不进入产品界面。

当前只制作三屏用于定调：

1. `01 首页`：紧凑品牌场景、唯一目标输入、两项高频服务与四项信息入口。
2. `03 打印参数`：真实文档预览占主位，参数、设备状态与核价确认集中在右侧。
3. `13 AI 助手`：目标理解、信息缺口和办理顺序，不使用聊天套壳。

打开方式：

```bash
python3 -m http.server 8932
```

```text
http://127.0.0.1:8932/docs/design/kiosk-ai-os-style-study-2026-08/index.html
```

支持 `?screen=home|print|advisor` 指定页面；支持 `?capture=1` 隐藏工作台外壳并按 1080x1920 原尺寸截图。

## 交互边界

- 首页目标输入、打印参数、AI 办理步骤可交互，但只改变本地原型状态。
- 价格始终显示“待服务端核价”，设备始终显示“检查中”，不会伪造在线、耗材、支付或出纸结论。
- AI 只能整理目标、缺口和顺序；支付、打印、删除、保存与外部跳转均保留本人确认。
- 其他 72 屏尚未展开；三屏视觉确认后再按八类母版扩展。
