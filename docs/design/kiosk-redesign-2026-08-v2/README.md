① 运行页偏离原稿（内页顶栏改深色、双标题、灰色禁用大按钮、五个旧版页面混用）；
② 「填满剩余高度」把卡片拉成空盒；③ 原稿可优化项：字偏小（首页 72% 文字 <22px）、

## 七条规则（每页都要过）

1. **可点的东西不放顶部。** 27 寸竖屏离地约 1 米，y<500 多数人够不着。顶部只放只读信息（标题、状态、步骤轨、小程序码——顶部正好是手机摄像头够得着的地方）。顶栏返回键保留（≥64×64），但底部 CTA 区要有回退路径。
2. **字阶比原稿约 +15%，不做大。** 用户是年轻人到中年人。取值：正文 22–24、辅助 20–21、卡片标题 28–30、页标题 32–38、小青问候 46、主按钮 26–28、导航 21、备案号 16–18；行高 1.4–1.5。
3. **每件事写明「带走什么」。** 新简历、面试反馈、材料清单、打印件、取件码；不写「进入 xx 服务」。
4. **一屏一句边界声明；工程词换人话。** 夹具、合同、pending、接口路径、HMAC、KSK-001、demo、taskId 不出现在用户可见文案里；原型演示面板隐藏。2026-09-28 统一扩充禁用词：服务端、会话、元数据、回执、链路、网桥、真机、未验收、uploaded、终端编号（KSK-001 / t_ksk_001）、英文眉题（SCAN VIA PANEL、MY ACTIVITY、NOTIFICATIONS 一类）；「数量以服务端返回为准」这类句子直接不写或写「以实际记录为准」，「会话」写「这次办理」。
5. **入口按托管 a 的真实口径。** 岗位、招聘会、找企业入口在我们云上不出现，相关位置改「机构官方渠道」；按钮文案守 CLAUDE.md §2 白名单；不伪造能力（没有真实数据不画「已完成 / 已保存 / 已打印 / 设备正常」）。
6. **字体只写栈，不打包（设计稿阶段）。** 实现阶段把思源宋体（标题）+ 思源黑体（正文）子集化 woff2 本地打包，不依赖系统字体。
7. **AI 是驱动层，每页保留与本步相关的 AI 入口和动作。** 首页「问小青」是米纸区第一主操作，AI 卡片角标写能力词（「AI 诊断改写」「AI 模拟面试」）；生成的内容旁贴显式标识「AI 生成 · 供参考」「AI 建议稿」；改写动作有「换个改法」「跟小青说几句，填进去」。原稿已有的 AI 元素只能移到够得着的位置，不能删弱。

不动的东西：颜色令牌、圆角、深绿 hero 与光晕、宋体标题、青字圆章、三 Tab 导航、信息架构。

## 方法

- 每页 = 原稿完整复制 + `</head>` 前追加 `<style id="qx2">` 覆盖块 + 最小 markup 改动；文件头 HTML 注释列出改了什么、对应哪条规则。
- 资源引用原稿目录：`../kiosk-redesign-2026-08/assets/…`，本目录不复制图片。
- 每页必须 Playwright 真尺寸渲染（`?capture=1`，有状态开关的页用「有内容」的态）并与原稿并排看过，才算完成；探针指标：<22px 文字数、y<500 可点元素、圆角框数。
- **改稿后必跑逐状态检查：** 在 `apps/kiosk` 下 `pnpm audit:qingxu-v2-drafts`（只看某几张加 `-- --only='^(21|13)-'`）。它把本目录每张稿的每个状态按 1080×1920 渲染一遍，查三件事：规则 4 的工程词与内部英文键名（`interview-report`、`taskId`、`fileId` 这类）、规则 2 的最小字号（20px，备案号与手机页 51 除外）、文字被别的元素压住（弹层盖住页面、`aria-hidden` 或 `pointer-events:none` 的水印印章不算）。状态清单与并排截图工具共用，有问题退出码为 1。
- 页面清单与状态见本目录 `STATUS.md`。
