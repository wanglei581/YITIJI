## 一、功能全集理解（设计的出发点）

一体机前台 8 大功能域，按真实交付物排列（不是按入口排列）：

| 域 | 功能全集 | 交付物 | 设计要点 |
|---|---|---|---|
| 打印扫描（P0 核心） | 手机传/U盘/到机码/ADF扫描 四通道 → 隐私预检 → 预览参数 → 服务端报价 → 支付 → 出纸 → 取件 | 打印件、扫描 PDF、图片合成 PDF、签章 PDF | 隐私预检不可绕过；只收纸张费 |
| AI 简历（唯一走全流程） | 上传/扫描 → 解析 → 诊断 → 优化 → 模板 → 生成 → 导出/打印；求职材料；签约风险提示（开关默认关） | 优化版 PDF、诊断报告、材料 PDF | 逐条裁决是核心交互；只新增版本不覆盖原件 |
| 岗位信息 | 第三方列表/详情/搜索、来源展示、外跳投递、收藏、平台目录、线下机构、找企业 | 二维码外跳、匹配报告（三档，无百分比） | 来源三要素必展示；无一键投递 |
| 招聘会 | 列表/详情、预约外跳、展位导览、资料打印、现场模式 | 活动资料、AI 参会准备单 | 现场模式是特色 |
| AI 助手小青 | 多轮问答、意图引导跳转、简历建议、打印帮助 | 对话本身 | 全局交互层，不是功能墙 |
| 政策服务 | 浏览、补贴材料清单/打印 | 材料清单 | info-only，不承诺到账 |
| 面试训练 | AI 出题 + 语音/文字作答 + 报告 | 练习报告（可打印） | 不评分不排名不预测 |
| 我的 | 概览 + 继续办；明细归位到各业务页 | 资产复用入口 | 不做聚合明细区 |

贯穿层：待机宣传屏、登录门禁（三选一无主次）、会话安全六态、帮助求助、法律协议、系统状态、我的资产。

**功能反推出的五条设计公理：**

1. **每条路径终结于真实交付物**（全产品 17 种），不许有死路页面。每屏都要让用户知道「这趟能拿走什么」。
2. **采集与履约是所有交付物共享的头和尾**：采集归一（四通道合并 + 预检不可绕过），履约归一（报价→支付→出纸→清空）。中间换加工/填槽/比对即可拼出所有功能。
3. **AI 长在步骤里，不表演**：采集步做预检、加工步做诊断、履约步做核价。AI 的存在感 = 省掉的步骤数，不是炫技动画。
4. **公共终端 + 站立触控 + 求职焦虑**：一屏一个主动作、触控目标 ≥56px、口语化短句、诚实空态（没有就画"不可预览"，不画假图）。
5. **合规内建而不是贴纸**：来源三要素长在卡片上、PII 脱敏默认开、朱砂色只给不可逆确认、外跳一律「去来源平台/扫码」。

## 二、视觉语言（青序流光 · 定稿规范）

已在 00–15、18 页验证的令牌，后续页面不得另起：

- **色彩语义**（继承 v3-themes 角色固定）：`--teal #1f9e86` = 本机服务/已验证状态；`--slate #3f68b0` = 第三方与官方来源；`--clay #b8683c` = 待核实/付费相关；`--cinnabar #b23a2e` = 需本人确认的不可逆动作。米纸 `--paper #f5f2e9` + 深墨绿 `--deep #0b241e` + 翡翠 `--emerald #2ee6a8` 仅用于深色区高光。**刻意避开紫蓝渐变**（AI 产品的通用皮）。
- **字体**：标题/小青问句用宋体（`.serif`），正文 PingFang SC。字阶：小青问句 40–44 / 区块标题 29 / 正文 19–23 / 辅助 17–19。
- **形状**：卡片圆角 24–32px，不用零圆角；用有机曲线（首页波浪分隔）破方正；不用厚重描边。
- **图标**：统一 lucide 线性 SVG 体系（stroke 1.9–2.4），图标必须对应具体业务，不用单字图标和随机插画。
- **结构**：`#stage` 1080×1920 居中缩放适配；顶栏（返回/logo/状态胶囊/时钟）→ 小青意图区（深色渐变 + 呼吸光环）→ 区块（编号 + 标题 + 右侧 hint）→ 底部 CTA 条 → 三 Tab 导航（首页/问小青/我的，不增加第四个）。

**密度红线（治 Claude 版文字墙）**：每屏信息预算 = 1 个小青问句 + 最多 3 个区块 + 1 个主动作；正文超过 2 行的说明必须拆成编号步骤或收进次级；区块内文字行数超过 6 行就要考虑拆屏。下半屏不允许大面积空白（用 `sec-grow` + `margin-top:auto` 把内容拉开）。

## 三、动效与科技感规范（Kiosk 可落地）

原则：**动效 = 状态的语言，不是装饰**。只用 transform/opacity（GPU 友好），全部支持 `prefers-reduced-motion` 降级，`?flat=1` 可一键关效。

| 动效 | 用在哪里 | 语义 |
|---|---|---|
| 呼吸点 breathe | 状态胶囊、进行中标记 | 活的、在服务 |
| 光环扩散 ring | 小青头像 | AI 在线、可对话 |
| 扫描线 sweep | 扫描工作台、重新扫 | 硬件在工作 |
| 纸张下落 paperdrop | 出纸进度（15 页） | 物理出纸的屏幕映射 |
| 进度条渐变填充 | 打印/处理进度 | 真实任务推进 |
| 原图↔修版对照开关 | 扫描结果 | AI 增强可验证、可撤回 |
| 硬件灯联动提示 | 出纸口/扫描槽 | 屏幕与机身一体（Hardware Grounding） |

不做：粒子背景、3D 翻转、页面间花哨转场（公共终端上是干扰）。

## 四、AI 功能落点（前端要体现的真实 AI 支持）

1. **文档嗅探零配置**：文件入池即识别类型（简历/证件/证书），自动预填参数预设（13 页已体现）。
2. **隐私预检**：证件自动加水印 + 「这是你的证件吗」确认门控（13 页已体现）。
3. **CV 修版**：纠偏/去阴影/白化 + 原图对照（18 页已体现）。
4. **OCR 结构化**：识别结果脱敏展示 + 可搜索 PDF 推荐（18 页已体现）。
5. **意图直达**：全局语音/文字问小青，意图胶囊一键解析多参数（05 页 + CTA 麦克风）。
6. **逐条裁决**：简历优化/隐私片段/AI 改动的「采纳/保留/自己写」三态 + 左右原文对照（待做：简历域）。
7. **证据标注**：E1 原文依据 / E2 本机数据 / E3 AI 推断，图例常驻（待做：简历域）。
8. **离人防窥与自清空**：离开倒计时清空 + 结束并清空朱砂按钮（15 页已体现）。
9. **断点续办**：跨设备会话续接（07 页已体现）。
10. **语义输出推荐**：按内容推荐去向（存手机/发邮箱/打印），免费与收费标清（18 页已体现）。
