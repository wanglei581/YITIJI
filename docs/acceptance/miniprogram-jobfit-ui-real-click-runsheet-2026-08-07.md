## 2. 执行步骤

### A. 进入岗位匹配

- [ ] 从「求职」Tab（或 AI 百宝箱 → 岗位匹配）进入 `pages/job-fit/job-fit`。
- [ ] 上传真实简历 PDF，等待解析成功（约 5–15s），确认进入 JD 填写/选择步骤。

### B. 匹配分析

- [ ] 粘贴真实 JD 原文，提交匹配；等待真实模型返回（约 8–60s）。
- [ ] 结果页出现三档结论之一（较高 / 中等 / 偏低），页面无百分比 / 录用概率 / 成功率文案。
- [ ] “JD 原文拆解”区出现职责 / 明确要求 / 优先条件 / 需留意分组，内容与粘贴的 JD 逐字一致。
- [ ] 逐项要求下显示“简历原文证据”或“缺口建议”，证据能在简历中找到原文。
- [ ] “有依据关键词 / 待补充关键词”列表有真实内容。
