## 0. 为什么是抽查而不是全量

5 个新页面按版式原型只有 4 类，且都建立在同一套全局类（`navbar` / `card` / `chip` /
`empty` / `list-state` / `actionbar` / `btn`）上。如果版式做法有系统性问题，它会同时出现在
所有页面上；只要抽查覆盖到「每类原型一个代表 + 本批新引入的 4 个视觉模式」，就足以判断。

**只要回答一个问题：有没有系统性版式问题？** 单页的细节瑕疵可以之后再逐条修。

## 2. 抽查项（5 项，每项看一眼即可）

### A. 共享外壳 —— 任选一页进入即可

- [ ] 顶部导航栏：返回箭头位置正常，标题不被微信胶囊（右上角 ··· ⊙）遮挡
- [ ] 页面底部内容不被底栏或安全区吃掉
- [ ] 卡片、标签、分隔线的间距与「招聘会详情」页观感一致，不明显偏松或偏紧

> 这一项若有问题，说明全局壳层出了事，**后面四项可以不看**，直接告诉我。

### B. 磁贴入口 —— 招聘会详情页

进入任意招聘会详情，滚到「现场助手」区。

- [ ] 四个磁贴（会场导览 / 参会企业 / 活动资料 / AI 参会准备单）2×2 排布不错行
- [ ] 磁贴内图标、标题、描述三行不重叠、不溢出
- [ ] 快速双击其中一个 —— **只应进入一次**，返回一次就回到详情页（不是两次）

### C. 长文本折行与截断 —— 参会企业列表

- [ ] 企业名很长时是否截断得体（不撑破卡片、不遮住展位号）
- [ ] 展区筛选条横向滚动正常，选中态可见
- [ ] 顶部搜索框内的输入光标与占位文字位置正常

### D. 图片渲染 —— 会场导览

- [ ] 有平面图时：图片按宽度自适应，不变形、不超出屏幕
- [ ] 点击平面图能放大（`wx.previewImage`）——**这项是我最不确定的**，
      平面图是短时签名 URL，可能在预览时已失效
- [ ] 没有平面图时：**整块不出现**（不该看到占位框或「暂无平面图」）
- [ ] 展厅卡片点击展开/收起正常，展开后企业清单不溢出

### E. 长内容与底栏 —— AI 参会准备单

需要账号里已有一份解析过的简历；没有的话应看到「去上传简历」引导而不是报错。

- [ ] 生成中只显示**真实已用秒数**，没有编造的「预计还剩」
- [ ] 结果页长列表滚动时，底部操作条不遮挡最后一条内容
- [ ] 准备清单前的方框是空的、点不动（这是有意的：画勾会被读成「已完成」）
