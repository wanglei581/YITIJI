# 路由图谱

「端点」是 **import 可达性上界**：页面能通过 import 链走到那个 service 模块，
不代表每次渲染都会调用它。用它回答「改这个接口会影响哪些页面」是可靠的；
用它回答「这个页面一定会发这些请求」不可靠。
