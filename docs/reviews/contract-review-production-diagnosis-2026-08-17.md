## 三、剩余范围

**任务已创建并进入分析，但队列处理器在日志中零活动。**
`pm2 logs --lines 2000 | grep -iE 'CONTRACT_REVIEW_(EXTRACT|ANALY|SAFETY|PROVIDER|QUEUE|TIMEOUT)'` 无任何输出，
而同期 `JobSyncScheduler` 日志正常，说明不是日志本身的问题。

三种可能，尚未区分：

1. 处理器注册了但静默空转（某个注册条件不满足，且未记录原因）
2. 入队的 queue name 与处理器监听的名称不一致
3. create 成功但入队那一步静默失败
