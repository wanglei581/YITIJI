# 一体机全功能用户模拟走查（2026-09-27）

> 目的：产品负责人要把「青序流光」新前端换到线上，要求「正常使用、一点问题没有、达到商用完整标准」。
> 本轮由 Claude（协调与亲测）、Codex（gpt-6-astra 极高，读代码）、Grok A / Grok B（grok-4.7-build-fast 极高，按用户实操）、
> Agy（gemini-3.8-flash-high，纯推理复核）四家分工，按真实用户把一体机每个页面、每个按钮走一遍，
> 找出哪里断、怎么接成完整闭环。
>
> 证据层级：**本地全栈**（候选 `89ec23228`，招聘托管关 = 托管 a，AI 用 mock、短信打日志、支付用沙箱、OCR 关）。
> 本文不代表生产验收、真实支付、真实 AI、奔图出纸或 Windows 现场验收。

## 一、结论

主链是通的：打印付款出纸、登录后的订单与文档、机构官方渠道、机构政策、紧急下架，全部亲手跑通。
离「商用完整」还差三类问题：

1. **两处必须先修的硬伤**：打印预览从来不显示文件内容（用户付钱前看不到自己要打的东西）；
   同一标签页换引导票后，下一位能在打印台看到并继续打印上一位的文件。
2. **「做完之后接不上」**：AI 结果、小青作业、报告直达打印，离开当前页后多数找不回、接不上打印，
   登录或返回时还可能换成别的文件。
3. **界面层没收口**：页面上直接写「服务端」「会话」「pending」「真机未验收」等工程词，
   还有托管 a 之前的岗位招聘会文案、十来个旧版页面、约 20 页一半以上文字小于 20px。

## 三、已亲手跑通的闭环

1. **游客打印**：手机扫码上传 → 一体机确认 → 材料检查 → 预览参数 → 服务端报价（3 页 × 0.20 元 = 0.60 元）→
   收银台 → 沙箱支付成功 → 取件码 → Agent 领任务 → 打印中 → 完成页（取走 3 页、订单号、文件删除时点）。
2. **登录后打印**：验证码登录 → 同上 → 「我的 → 打印订单」显示 ¥0.60 已支付、已完成 → 「我的文档」有这份文件 →
   点「打印」直接到报价确认，可再打。
3. **本机构官方渠道**：机构后台新建 → 管理员把机构内容信任设为有效 → 一体机首页磁贴和官方渠道页出现。
4. **机构政策**：机构新建 → 机构自审通过 → 勾选对内容负责并发布 → 一体机「查政策 → 就业政策」可见，
   可打开详情、上传自备材料打印、扫码打开来源链接。
5. **紧急下架**：管理员下架一条渠道、一条政策 → 一体机立即看不到 → 机构收到两条通知 →
   机构不能再编辑或重新发布（403）→ 管理员面板显示下架态。
6. **托管 a 边界**：岗位、招聘会、企业、线下机构页全部关闭；旧的「线上平台」地址转到官方渠道。
7. **结束使用与超时清场**（Grok B）：结束后我的简历、记录、首页都不再有上一位信息；
   超时预警页显示脱敏手机号和倒计时，到时清场。

### 本地环境缺口（不算产品缺陷，生产必须核对）

- 本地库没有打印价目 → 报价失败。生产要确认 `PriceConfig` 黑白、彩色两行都在，且描述与单价一致。
- 本地没设 `KIOSK_PUBLIC_BASE_URL` → 手机上传二维码指向接口地址（A-02、B-01）。生产启动时强制要求 https 地址，但要核对值指向一体机前端。
- 本机没有 Agent（9527 端口）→ U 盘、扫码登录（B-08 还要求一体机构建带网桥令牌）、扫描投递都走不到。
- 没有 AI 密钥 → 简历对照、职业规划、模拟面试、小青回答都走不到结果（B-02、B-04、B-05）；这几条的「AI 挂了怎么退化」算作产品问题，已并入 B-06、B-07、A-04。
- 没有 Word 转换引擎（B-15）→ 只收 PDF 和图片。生产是否装，待拍板。

## 六、修复分批

按「每批能单独上线、能单独验收、不互相卡」排。编号对应第四节。

**W1 止血（P0，全部可本地验证）**
- 预览真渲染（C-01）：打印预览与导出预览逐页显示文件内容，并保留「页面跳走不报 ERR_ABORTED」的约束。
- 换票即清场（C-02）：引导票交换成功时走同一份敏感状态清单。验收：本轮复现脚本转绿。
- 一体机不弹系统文件框（C-14、C-11）：终端模式下所有本机文件入口不渲染；备案号在一体机上显示为文字，网页访问仍保留链接。
- 样例开关只在开发构建生效（F06、F18）；语音会话接口加终端身份守卫（F04）。
- 签名盖章（F03）：拍板前先撤掉「印章图片」引导文案；服务端范围按 #20 拍板执行。

**W2 一条打印交接（根因：各处用临时跳转状态传文件）**
