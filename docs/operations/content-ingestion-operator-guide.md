# 机构后台使用指南（托管 a）：机构资料、官方渠道、政策与本机构终端数据

> **状态（2026-09-29）：** 试点前交付物（next-tasks P1-11）。写的是两个后台收口批次（#1057、#1065、#1076、#1080、#1082）合入后的界面，菜单名与一体机入口名按试点交付物包的「术语对照」统一。这些 PR 合入并发布之前，线上界面可能还是旧样子，以本机实际为准。旧版录入指南（岗位、招聘会发布到一体机）已停用，只在 git 历史里保留。

写给运营机构的后台操作员，也给本公司管理员核对用。现场工作人员的培训材料（加纸、卡纸、「打印结果未确认」等）在试点交付物包里，不在本文。

**先说清楚定位。** 本公司是设备与软件供应方，没有人力资源服务许可证。托管 a：本平台不再展示、不再新增岗位、招聘会、企业资料，已有的存量正在清理中；一体机只在本机构自己的终端上放本机构官方渠道的二维码。政策由本机构自己审核、发布并署名，本公司不代写、不代审、不代发，只在违法违规等紧急情况下单向下架。系统不接收、不转交任何求职者简历，机构后台看不到任何用户的个人明细。

## 1. 登录与账号

1. 用浏览器打开本公司提供的合作机构后台地址（开通通知里给出）。登录页写着「职易达 · 合作机构后台」。
2. 用机构账号 + 密码登录；已验证过的手机号或邮箱也可以当账号用。「验证码登录」只支持已验证的手机号。
3. 忘记密码点「忘记密码？找回 / 重置」，用账号绑定的手机号收验证码后设新密码。
4. 菜单「账号」里只能改自己的密码：新密码至少 12 位，含大写字母、小写字母、数字、特殊字符中的 3 类。改完会自动退出，用新密码重新登录。
5. 一人一个账号，不共用、不外借。子账号、停用账号、换绑手机号由本公司在管理员后台办理。

## 3. 工作台

- 「平台处置通知」：本公司紧急下架本机构的政策或官方渠道时，这里留一条记录，写明对象、事由和说明。紧急下架不能恢复，看到后请按第 6 节第 7 条处理。
- 页面顶部若出现「本机构的内容目前还不会出现在终端上」，说明本机构还没通过内容可信核验，见第 4 节。

## 4. 机构资料与内容可信

1. 机构名称、机构类型、场景模板、开通的模块由本公司核验后配置；本机构自己只能改联系人和联系电话（右上角「编辑联系方式」）。
2. 「内容信任与发布权限」一栏显示本机构的核验状态：
   - **内容可信（允许发布）**：本机构审核通过的政策可以发布到终端。
   - **待核验 / 未标记（暂不可发布）**：政策可以录入、审核，但发布不到终端。找本公司办理核验，需提供授权书、合同或公开声明编号等依据。
   - **已暂停 / 已撤销 / 已归档（禁止发布）**：所有内容都不会在终端展示。原因和恢复办法问本公司。
3. 「可用官方域名」是本公司按本机构入驻时的盖章确认函登记的域名（只读）。官方渠道的链接只能落在这些域名或它们的子域名下；没登记域名之前不能添加渠道。

## 5. 本机构官方渠道

一体机首页的「机构官方渠道」磁贴，点开是「本机构官方渠道」页：一排二维码，用户用手机扫码去本机构官网或公众号查看、办理。二维码只出现在绑定了本机构的终端上；本机构一个启用的渠道都没有时，这个磁贴不出现。

在「机构资料」页的「本机构官方渠道」小节里维护：

1. 点「添加渠道」，填名称（最多 40 字）、链接、排序号（越小越靠前）。
2. 链接要求：https 开头；不带账号、不带非 443 端口；域名必须是「可用官方域名」之一或其子域名；链接里带跳转参数的，跳转目标也必须在这些域名内；商业招聘网站不能设为官方渠道。页面会提前提示，能否保存以服务器判断为准。
3. 保存后可以「启用 / 停用」。停用后约半分钟内，一体机不再显示这个渠道。
4. 不再用的渠道点「归档」。
5. 被本公司紧急下架的渠道显示「平台已紧急下架」和事由，不能再启用或修改，只能归档。

一体机上二维码下方会写明：本渠道由本机构提供，信息以其官网为准。

## 6. 政策公告

一体机首页「查政策」里的「就业政策」「政策公告」读的就是这里发布的内容，并标明发布机构。

1. **谁能新增：** 只有公共就业服务机构和高校就业中心能新增政策。其他类型的机构看得到已有内容，能审核、下架、删除，不能新增。
2. **录入：** 点「新增政策内容」，选内容类型（政策公告 / 政策扶持条目）、标题、分组、摘要、正文、来源或办理链接、展示日期。保存后进入「待审核」，终端不展示。政策里不写岗位、招聘会信息和报名链接，不承诺「补贴必到账」「代为申请」。
3. **审核：** 列表里点「审核通过」。审核通过不等于发布。
4. **发布：** 点「发布」，在弹窗里勾选发布责任确认后发布。系统记下确认人、时间和内容版本，一体机随即可以看到。
5. **修改：** 已发布的政策修改后会生成新的内容版本，并**立即从终端撤下、回到待审核**，要重新审核、发布。
6. **下架与删除：** 过期或不再适用的点「下架」，终端不再展示；删除不可恢复。
7. **平台紧急下架：** 本公司因违法违规、虚假信息、权利投诉或主管部门要求等紧急情况下架的政策，列表里显示「平台已紧急下架」，下方写事由、说明和下架时间。这一条已冻结：不能再编辑、审核或发布，只能删除。更正后的内容请新建一条，由本机构重新审核发布。
8. **申领条件（政策扶持条目才有）：** 点「申领条件」，按政策原文逐条录入可机械比对的条件，一体机据此给用户「相符 / 不符 / 无法判定」的比对结果，不做资格认定。保存后这条政策会回到待审核，本机构审核通过并确认发布后，一体机上的条件核对才会用上这组条件。机器判不了的条款标「只能人工核对」。

## 7. 终端数据（试点签收指标）

菜单「终端数据」只统计绑定到本机构的终端；终端由本公司绑定，本机构还没有终端时页面会写明。

- **周期：** 近 7 天 / 近 30 天 / 近 90 天（按北京时间自然日起算，截止到当前）。
- **服务人次：** 一体机的使用次数——从待机唤醒或上一位清场之后，第一次进入某项服务算一次，误触不算；按终端当时所属的机构统计。一体机开始上报使用会话之前显示「暂无」。
- **打印扫描服务次数：** 本机构终端上新建的打印任务与扫描任务数，按任务计，不等于人次。
- **出纸成功率：** 出纸成功 ÷ 统计期内结束的打印任务；成功含现场工作人员核查「已出纸」的单，取消、作废与进行中的不计。「超时未确认、待现场核查」单列，这些单在分母里按失败算，所以比率是保守值。
- **AI 可用率：** 目前 AI 调用记录还没有标明是哪台终端发起的，页面写「暂不能按本机构终端统计」，不拿全平台的数字代替。
- **故障与恢复：** 相邻两次心跳间隔超过 5 分钟记一次离线；打印机从报异常到重新报正常记一次故障；给出次数、时长、平均恢复时间、最长一次、当前是否还有未恢复的故障。统计期内一次心跳都没上报的终端（从未连接或整段离线）显示「统计期内没有上报心跳，无法统计」，不算作「没有故障」；合计里会写明另有几台未计入。
- **少于 5 的数字：** 为避免对上具体某一单，1–4 次的计数显示「少于 5」；已结束的打印任务不足 5 单时不给出纸成功率。
- **逐台明细：** 表格可按在线、有未恢复故障筛选，按名称或编号搜索；点一行看这一台的全部数字与口径。
- **导出：** 右上角「导出 CSV」，文件名含机构名与起止日期，开头几行写统计窗口与口径说明，最后一行是合计。导出内容与页面一致，不含任何个人信息。

## 8. 数据大屏与数据统计

- **数据大屏**（页签：机构总览、信息使用、终端孪生）：看本机构终端是否在线、是否正在打印，以及本机构内容的在架与使用情况。部分指标还在补齐，页面上如实写着「待补齐」，不是故障。
- **数据统计：** 本平台只统计政策的在架、待审核等数量，岗位、招聘会不在本平台。

## 9. 智慧校园（仅高校就业中心）

在「终端开关」里配置本校终端首页是否显示智慧校园入口，保存后联动一体机首页。只能配置归属本校的终端。迎新内容、使用统计尚未开放，页面如实写「未开放」。

## 10. 本平台不做的事

- 不再展示、不再新增岗位、招聘会、企业资料（已有存量正在清理中），不代审、不代发、不代改任何招聘类内容；用户问招聘，请他扫「本机构官方渠道」的二维码去本机构官网办理。
- 不接收、不转交求职者简历，没有候选人、投递、面试邀约功能，也看不到任何用户的个人明细。
- 客户需要完整的岗位与招聘会功能时，按托管 b 私有化部署到客户自己的服务器或政务云，由客户运营。

## 11. 遇到这些情况就停下来，先联系本公司

- 有人要求把岗位、招聘会或企业资料录入我们的云。
- 官方渠道链接的域名不在「可用官方域名」里。
- 自营点位被要求打开招聘类内容。自营点位只作演示与材料出口。
- 工作台出现「平台处置通知」而不清楚原因。
- 账号出现不是本人做的操作，或怀疑密码泄露：先改密码，再告诉本公司。
