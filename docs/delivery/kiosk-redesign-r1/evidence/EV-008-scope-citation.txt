§2 不能做的功能（8 条禁止项）：平台内一键投递 / 平台内收简历给企业 /
  企业端候选人筛选 / 面试邀约 / Offer 管理 / 候选人推荐 /
  自营网络招聘闭环 / 企业自主发布岗位并直接收简历。
  按钮文案白名单：查看岗位、去来源平台投递、扫码投递、查看招聘会、
  去来源平台预约、扫码预约。禁用：一键投递、立即投递、平台投递。

§9A 核心页面范围：一体机前台 / 管理员后台 / 合作机构后台三端逐项列出。

§10 数据边界：外部岗位与招聘会必须带 source_org_id、external_id、
  source_name、source_url、sync_time、review_status、publish_status；
  系统只记录浏览/收藏/外部跳转/打印/AI服务调用，不记录企业筛选结果。
