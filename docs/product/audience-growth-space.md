## 0. 先更正一个数

此前评审合成页里写过「蓝领约 28% 求职受骗」。**这个数仓内追不到一手来源**（只出现在一份临时合成文件里，
三家评审原文都没有），本轮已撤。可以写进正式文档的是定性结论：**怕被骗是这个群体的第一痛点**，
依据是人社部门持续曝光的「招转培 / 保录内推 / 押金服装费 / 境外高薪」类求职陷阱，以及三轮评审独立收敛。
**任何百分比在拿到可引用来源前不得写入本文或对外材料。**

## 1. 切分：不用「蓝领 / 白领」当功能表头

「蓝领 / 白领」是产品负责人的用词，在点位和销售上够用，在功能取舍上不够用 —— 它把三件不同的事捆在一个词上：
点位（人社大厅 vs 高校写字楼）、材料形态（纸和证 vs PDF 多版本）、伤害类型（怕被骗 vs 怕写不好）。
同一台机器前两种人都会出现；45 岁柜员可能只带纸，职校生可能很会用微信。

仓内已经同时存在四套人群语言：OS 方案 §3.2 的处境五类、政策文档的受众六类、语音简历注释里的「蓝领」、
小程序首页默认问候「同学」。再把二分当 SSOT，功能顺序不会变，文案会继续互殴。

**本文的切分：保留 §3.2 处境五类，只加一层「履约形态」，只有两个值。** 不做三轴八格 —— 没有观测数据可填。

| 值 | 口头别名 | 材料逻辑 | 可观察行为（不靠用户自报） | 默认主表面 |
|---|---|---|---|---|
| `hall_paper` 现场纸质履约 | 蓝领 | **凭证型**：身份证、技能证、健康证、纸质简历 —— 用事实和证件说话 | 进的是大厅 / 街道 / 零工点；材料是纸、证、U 盘；**常常是家属或专员代操作**；要当场拿走纸 | **一体机**。小程序是家属准备面 + 到机码容器，不是本人工作台 |
| `phone_digital` 数字迭代准备 | 白领 | **叙事型**：经历、项目、STAR、JD 匹配 —— 用叙事和包装说话 | 在手机上反复改；要版本、面试、规划；到机是临门一脚 | **小程序**准备 → 一体机出纸 |

§3.2 五类仍回答「这一趟是校招、临时候补、赶招聘会、进厅办事，还是长期耗着」；履约形态回答
「材料从哪来、谁点屏幕、要不要当场出纸」。两层相乘，**不新开产品线**。

### 这个切分可以被这三条推翻（命中就改模型，不加维度）
1. 若首批大厅观察里多数人自己扫码、自己在手机改完再来打 → `hall_paper` 降为无手机兜底，不是主路径。
2. 若校招季一体机订单里「多版本简历 / 面试报告」占比很低 → `phone_digital` 的「持续关系」是方案幻想，两端都按现场履约做。
3. 若 BD 不说蓝领白领就卖不掉 → 只证明这两个词是点位话术，仍不是功能表头；保留别名列即可。

## 2. 需求与现有能力（在服务 / 空转）

合规红线不变：不投递、不收简历、不企业端、不候选人推荐、不代办。

### 2.1 `hall_paper`

**前三个真实需求（按我们能履约的排序）**
1. **先确认「这活是真的、这地方会不会先收我钱」。** 一体机已有「来源四要素缺一不放行外跳」，但那是目录完整性门禁，
   不是对岗位正文里「高薪保录 / 押金 / 培训费 / 不签合同」的体检；内容筛查刻意不含虚假宣传（合规文档已登记该缺口）。
2. **把纸变成能用的材料，当场拿走。** 一体机已有简历扫描、证件扫描、U 盘导入。这是这个群体和打印终端的交点。
3. **合同 / 入职手续里的坑，用能看懂的话说明，能打印带走。** 合同审查类型已含劳动合同；对这个群体，劳动合同比 Offer / 竞业更贴身。

**现有能力审计**

| 能力 | 判定 |
|---|---|
| 纸质扫描 / U 盘 / 证件扫描 / 打印全链 | **主路径，尚未真机履约** |
| 语音说简历（题库已用仓库操作工 / 电工 / 保洁 / 电焊 / 叉车） | **空转**：入口在首页第一卡，`ASR_PROVIDER` 默认 disabled，等于把入口做成了装饰 |
| 来源四要素 / 线下机构资质 | 在服务目录可信，**不服务「这份工会不会骗我」** |
| 合同审查 | 在服务，但产品语言是「AI 签约风险提示」，大厅用户听不懂 |
| AI 诊断 / 优化 / 模板 / 模拟面试 / 职业规划 / 岗位匹配 | **错位供给**：按叙事型生产函数做的，不是这个群体的第一痛 |
| 材料包 | 已立项，尚未履约；现有 PRD 模板是「招聘会标配包」，**不适配大厅** |
| 家属协助 | §3.2 写了一句「家人协助」，代码里没有代为准备的授权模型 |

**12 个月可长的（红线内、材料服务网内）**

| 可长出的 | 依赖 |
|---|---|
| **岗位可信体检 v1**：对已审核岗位 + 用户拍的招工短信 / 纸质广告 OCR，输出「收费 / 押金 / 培训 / 不签合同 / 来源不可核」三级提示，**可打印一页带走**。不说「这是骗子」，不建企业黑名单 | 审核产能；OCR；**不依赖拿证** |
| **劳动合同风险提示前置到大厅首页**，题库改成押金、培训费、不缴社保、不签书面合同 | 现有 contract-review；硬件扫描；**不依赖拿证** |
| **大厅材料包**：身份证复印件 + 纸质简历 + 资格证 + 政策材料清单，一次出纸 | 材料包立项（须另开「大厅材料包」模板，不硬套招聘会包）；扫描真机；**不依赖订阅消息** |
| **家属机模式**：本人不登录微信；小程序允许家属用自己的微信准备、到机码给本人。**本人资产不对代办者展开简历原文** | 账号模型要加「代为准备」授权；隐私评审；**不依赖拿证** |
| 政策指引单打印（info-only） | 人社作为数据合作方供数 |
| 身份证读卡登录、大字模式 | 硬件 + 政企订单；无订单不做 |

**对小程序默认假设的修正 —— 推翻一半，不是整端作废。** 现行 §1.1「微信登录 → 私密准备 → 材料包 → 到机码」
对这个群体有三处不成立：微信登录的人不一定是求职者（可能是子女）；准备发生在大厅 27 寸上，纸是输入不是输出；
「持续关系 + 订阅消息」不是第一年的杠杆。**小程序对这个群体的正当角色是家属操作面 + 到机码容器。**
不因此删小程序；删的是「这个群体也要从今天页开始经营」的假设。

### 2.2 `phone_digital`

**前三个真实需求**
1. **把经历变成可投的材料，并保留版本。** 品类里「生成免费、导出收费」是通病；本产品的差异是线下出纸，不是再做一个线上简历站。
2. **面试前能练、练完有可打的报告。** 报告只给本人。
3. **临门一脚不丢材料：行前打包、到机出纸、招聘会补打。** 这是材料包 PRD 的原问题。

他们也怕被骗，形态不同：付费实习、招转培、假 Offer、竞业。合同审查的实习协议 / Offer / 竞业类型是给他们的。

**现有能力审计**

| 能力 | 判定 |
|---|---|
| AI 简历表单 / 上传 / 诊断 / 优化 / 生成 / 模板 / 出纸 | **主供给，在服务**（真机 / 生产仍 NO-GO） |
| 模拟面试、职业规划、岗位匹配参考、自我探索 | 在服务；匹配不得百分比、不得回传企业 |
| 材料包 | **关键空转**。两端故事都写了，后端下单不存在 |
| 一体机上的长文本简历编辑 | **空转**：站在大厅 27 寸屏打字超过 5 分钟不成立 |
| 生活圈 v0.1 | 贴皮，已判定换形状（见 next-tasks 生活圈判定） |
| 岗位 / 招聘会 / 企业信息 | 在服务为入口；生产目录空，对用户是空壳 |

**12 个月可长的**

| 可长出的 | 依赖 |
|---|---|
| **材料包真正下单 + 到机履约**（招聘会标配包 + 自由组合） | `POST /orders/package`；真机出纸；不拿证 |
| 简历版本 / 任务恢复 | 现有 `AiResumeResult` 聚合即可，不先建任务平台 |
| 岗位可信体检（链接回传 + Offer / 实习协议） | 复用合同审查；审核产能；不拿证 |
| 订阅消息：到机提醒、招聘会行前提醒 | 微信订阅消息（全仓当前 0 处） |
| JD 靶向剪裁 | 不做匹配百分比、不做「ATS 通过率」承诺 |
| 拿证后才评估的投递记录回流 | **12 个月内当不存在**；闸门 fail-closed 且零调用点 |

**两端不做两套人格包。** 同一套能力，默认排序不同：大厅首页先扫描 / 体检 / 劳动合同 / 出纸；
小程序首页先材料包进度 / 简历版本 / 面试。语音简历留给「不方便打字」，不是「我们有蓝领版」。

## 3. 发展空间里明确不走的

带偏 = 变成招聘平台 / 内容 App / 金融或培训导流 / 让一体机变打印机。

**`hall_paper`**
1. **「帮他找个靠谱的活 / 帮他报名」** —— 大厅里最自然的下一句。做了就是平台内撮合。正确终点是打印风险提示单 + 来源平台二维码，人自己决定去不去。
2. **「推荐培训 / 考证 / 贷款，帮他提高就业」** —— 这个群体的被骗路径本来就是招转培、考证保过、垫资购车。产品一旦出「技能提升推荐」并抽成，就站到骗子同一条价值链上。**一体机变打印机**是这条的失败态。

**`phone_digital`**
1. **把「职业生活圈」做成求职内容 App** —— 停留时长、日活、社区帖会反过来要求假动态。已判定 v0.1 换形状。
2. **做成「超级简历 + 在家打印」，让人不再到机** —— 七月渠道方案已把这写成战略误区。附带：岗位匹配做成按企业聚合的候选人漏斗，合规文档 §4.4A 已禁。

**两个群体共用的禁令，写在这里不只写在合规页：不导培训、不导贷款、不导保险、不做社区、不代投。**

## 4. 维护与重写触发

- **具名拍板**：产品负责人。评审轮次结论经负责人认可后入库；工程不得因本文新开首页入口、底部 Tab、同义卡片。
- **不维护**：BD 话术、点位投标附件 —— 那些继续用「蓝领 / 白领」别名，从本文抄一表即可。
- **命中任一条就整节重写，禁止追加**：
  1. 首批人社 / 街道 / 高校点位有真实进厅观察（哪怕 30 人），足以支持或打脸 §1 的三条反驳。
  2. 生产岗位 / 招聘会目录不再为空，或材料包第一次真实出纸。
  3. `ASR_PROVIDER` 打开且语音简历有真实完成率。
  4. 取得人力资源服务许可证，或产品负责人签字放宽八条红线中的任何一条。
  5. 本文落地 12 个月仍无大厅观察 → 把 §2 发展空间整节改标「未验证，停止按此排期」。
